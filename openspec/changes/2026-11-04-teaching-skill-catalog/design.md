# 教学目录设计

每项技能以目录中的 SKILL.md 为入口，目录清单提供中文名称、教学方向、工具需求和来源版本。改编的上游原文按需读取，教学流程以平台适配版为准。

选择应用时组合该应用推荐的教学技能与已有个人上传技能，知识库偏好保持原值。保存失败恢复前一个选择。服务端继续校验每个技能 ID 的所有者或内置可见性。

历史配置通过旧 ID 到新教学 ID 的映射解析，没有替代项的旧内置技能退役。GET 仅返回有效解析结果，持久化配置由显式保存完成。真实存在脚本资源时才注册脚本执行工具。

服务配置只复制模型、Embedding 和 SMTP 变量，数据库与认证密钥继续使用小组独立值。测试运行强制清除外部密钥并使用 mock，真实模型验证使用显式 --real 与合成样例。
