# 安全与数学展示

## ADDED Requirements

### Requirement: SM-001 共享认证限流
系统 SHALL 对登录 IP 每分钟 20 次、规范化邮箱每 15 分钟 10 次执行跨进程共享限流；验证码无论是否登录均按 IP 和邮箱每小时 10 次限流，并保留同一邮箱用途 60 秒发信间隔。计数仅存储 HMAC，超限返回 429 和 Retry-After。

#### Scenario: 并行尝试与窗口结束
- **WHEN** 多个进程并行尝试同一邮箱或同一 IP，随后计数窗口到期
- **THEN** 并行请求共享额度，超限被拒绝，到期后恢复额度

### Requirement: SM-002 只读配置与成员隐私
系统 SHALL 在配置 GET 中只读取业务记录，不存在时返回内存默认值；PUT 持久化配置，兼容旧绑定。仅任课教师成员列表包含邮箱。

#### Scenario: 新用户读取与保存
- **WHEN** 学生首次读取配置及成员，再保存配置
- **THEN** GET 不创建助手配置且成员不含邮箱，合法 PUT 保存配置；教师仍可获取成员邮箱

### Requirement: SM-003 有界 MCP 响应
系统 SHALL 在 SSE 分行或 JSON 解析前按解码后响应字节累计限制到 3 MiB，对整个 tools/call 限时 55 秒、其他 RPC 限时 15 秒。

#### Scenario: 超长行或持续事件
- **WHEN** 服务返回超长单行、累计超限事件或持续滴流
- **THEN** 客户端停止读取并返回明确失败；分块 UTF-8、CR/LF 和正常匹配响应仍可解析

### Requirement: SM-004 安全数学展示
系统 SHALL 在历史和流式回复的共用 Markdown 渲染中支持美元及反斜杠的行内、块级公式，保留代码与转义美元符号；未完成公式暂作文本，错误公式不阻断回复。KaTeX 样式和字体本地加载，禁用可信命令并保留 HTML 净化。

#### Scenario: 公式、恶意输入与窄屏
- **WHEN** 回复包含分数、根号、矩阵、多行推导、未闭合公式、恶意命令或长公式
- **THEN** 完整公式可读，错误/未完成内容安全降级，不执行脚本，窄屏长块级公式在自身区域横向滚动
