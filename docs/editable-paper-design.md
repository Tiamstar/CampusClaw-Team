# 原卷、识别与题库的数据边界

2026-11-17，响应真实试卷与基本管理操作缺失的反馈。不是全系统CRUD已完成声明。

## 数据格式与约束

| 数据 | 保存方式 | 原因与约束 |
| --- | --- | --- |
| 上传原卷 | ExamSource文件、SHA256、original_name | 显示名称可改，解析扩展名来自存储文件；不覆盖原文件 |
| 识别/未完成整理 | draft JSON，groups/material/questions/source_units | 可保存未补答案的内容；服务端统一类型、长度、题型、来源校验 |
| 题库实体 | QuestionGroup、Question、QuestionAsset外键 | 材料一次保存，子题独立编辑，图片私有授权；题库不要求分值 |
| 原卷题目索引 | ExamPaperEntry | source/question外键PROTECT，source+question及source+position唯一约束；不再以JSON中的裸ID作为唯一索引 |
| 编辑记录 | ExamPaperRevision | source+revision唯一，schema_version=1，保存编辑者、内容及时间 |
| 考试 | Quiz组卷分值、QuizAttempt开考快照 | 修改题库不改变已开始答卷、作答或成绩 |

兼容保留旧mapping JSON作为接口投影，索引写入与投影更新在同一事务内；既有已入库源迁移为外键索引。未改变旧答卷格式。JSON用于草稿与历史快照，不替代实体间参照完整性；非关系化字段未来升级须明确schema_version迁移。

整卷保存先验证全部题目/图片/来源和题组、题目修订号，再同步题库。Course与ExamSource锁协调写入。题库单独新增/编辑和题组排序也更新原卷版本与索引；过期页面返回409，保留本地编辑。移除题目停用旧实体，归档原卷可恢复；不物理删除关联成绩。停用状态不会因普通整卷保存被偷偷恢复。

## 操作流程

上传PDF/DOCX/TXT/图片，或按选择顺序合成最多12张照片 → 多模态模型读取文字和页面 → 结构化草稿校验 → 原卷与题目并排校对 → 预览整卷 → 明确确认入库 → 后续仍在同一工作台修改整卷并同步题库 → 组卷时设分。

前端新增整卷目录、逐题编辑、新增/移除/排序/转移小题、共享材料、选项与可空答案、原页框选配图、预览、保存记录、原卷搜索/重命名/归档/恢复；题库新增搜索及停用/恢复入口。手机相机入口是浏览器capture提示，不保证每个浏览器都会直接启动相机。多页照片上限12页、合计20MiB；PDF仍最多12页，完整28页样本没有冒充整卷已识别。

## 真实样本结果

来源为AQA公开2023数学试卷：
https://filestore.aqa.org.uk/sample-papers-and-mark-schemes/2023/june/AQA-83003H-QP-JUN23.PDF

样本仅留本地课程6，下载原件与变体在仓库外 `.paper-samples`，不作为自创题目或开源素材提交。

- 来源9：原卷第2–4页、Q1–Q6，首次模型连接失败，显式重试后6题齐全；初始识别把独立题捆成1组、复合题只留选择，需整理，未自动入库。
- 来源10：第4页真实几何图片，首次成功，包含A/B两个裁图。浏览器人工把选择与说明理由分为2个共用材料子题，确认入库为题目18、19；入库后修改第一题并同步保存，版本5。未代替教师确认答案。
- 来源11：同页增加倾斜/暗光/轻微模糊的模拟照片，前两次连接失败、第三次成功；新版提示返回single+short两子题。自动裁图仍夹带邻近文字，须教师框选修正。模拟失真不是真实手机拍照，尚无实拍验收结论。
- 官方英语阅读材料Insert已下载；对应Question Paper地址返回非PDF，未声称英语完整试卷识别或入库完成。

识别继续使用deepseek-v4.1-flash。Harness负责授权、输入适配、结构校验、存储和教师可编辑性；不是用手工解析替代模型识别。没有自动重放失败；首次失败与显式重试模型审计仍在。
