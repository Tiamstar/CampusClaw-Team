# 实现 P0 教学闭环

状态：提议中，待评审；优先级：P0；实现：未开始。

## Why

初步设计的主要增量是 E1、E3、E4、E5。它们通过统一知识点连接测验、答疑、成绩证据和复习建议，避免把 AI 功能做成与教学数据脱节的通用聊天框。

## What Changes

- 新增五类题题库、组卷快照、限时作答、版本保存、幂等交卷与评分复核。
- 新增课程论坛、相似帖提示、带来源的 AI 答疑草稿与教师发布。
- 新增成绩册、知识点学情、Excel 导出和带证据的 HTML / PDF 诊断报告。
- 新增知识点与先修关系校对、资源挂接、掌握度、复习路径与间隔提醒。
- 新增答疑草稿、学情诊断、知识点抽取三项可启停技能，及成绩、测验统计、掌握度三个只读 MCP 工具。

## Capabilities

### New Capabilities

- `quiz`：E1 测验、题库、答案快照与确定性评分。
- `forum`：E3 论坛治理和教师审核的 AI 答疑。
- `gradebook`：E4 成绩、统计、报告与只读数据工具。
- `knowledge`：E5 知识图谱、掌握度和复习计划。

### Modified Capabilities

无既有生效规约。底座的授权、AI 和审计约束作为共同前置，不在此复制或削弱。

## Impact

李非凡主责 E1 / E4，陈志康主责 E3 / E5，彼此交叉验收。共享知识点、成绩事件与引用契约见 [架构与数据契约](../../../docs/architecture-and-contracts.md)。验收编号为 AC-Q、AC-FR、AC-G、AC-K 系列。

## Dependencies And Non Goals

依赖底座身份、资料检索、模型网关、任务和审计。P0 提醒采用持久化站内待办，不依赖 E7 邮件 / 日历；资料引用可回查，不依赖完整 E6 预览。不做自动作弊定性、AI 最终判分或 AI 自动公开发布。

判分和学情口径是待评审的工程草案；教师确认前不使用真实学生成绩验证产品效果。
