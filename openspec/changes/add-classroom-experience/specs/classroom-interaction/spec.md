# E2 课堂互动

## ADDED Requirements

### Requirement: INT-001 限时签到与补签

系统 SHALL 允许教师发起数字码或二维码限时签到，服务端校验课程成员、有效码与时间窗口，同一学生同一活动只记一次出勤；教师补签须留理由和审计。

#### Scenario: 签到与补签
- **WHEN** 学生在窗口内使用有效码签到，或教师为缺勤者补签
- **THEN** 出勤列表与统计一致，重复签到不重复计数，补签保留操作者、原因与时间

#### Scenario: 过期码或他班用户
- **WHEN** 使用失效码、在窗口外提交或他班学生尝试签到
- **THEN** 拒绝并说明可公开的原因，不泄露活动敏感信息或改变统计

### Requirement: INT-002 投票抢答与重连统计

系统 SHALL 支持教师发起投票、抢答和随堂选择题，按活动规则去重并提供即时统计；实时消息带序号，断线重连可补发或恢复服务端快照，统计以持久化数据为准。

#### Scenario: 参与与重连
- **WHEN** 两名学生参与后其中一人断线并重连
- **THEN** 统计与数据库一致，重连恢复遗漏状态，重复消息不增加票数或抢答次数

#### Scenario: 活动关闭与消息乱序
- **WHEN** 关闭后提交、消息乱序或重复到达
- **THEN** 拒绝新作答并忽略过期重复事件，不将客户端时间作为抢答排序依据

### Requirement: INT-003 匿名提问与出勤可见性

系统 SHALL 为课堂提问提供对同学匿名的展示并保留可审计身份，教师可管理内容和查看本班出勤；学生只查看自己的出勤，匿名信息不得经实时消息泄露。

#### Scenario: 匿名提问展示
- **WHEN** 学生发送匿名问题且教师管理该提问
- **THEN** 同学仅见匿名内容，教师可按授权回查身份，管理动作可追溯

#### Scenario: 越权查看或恶意消息
- **WHEN** 学生查询全班出勤、他班活动或发送脚本内容
- **THEN** 权限请求被拒绝，文本被安全处理，不广播真实匿名作者字段
