# 评分量规设计

先读任务要求、学习目标、满分和既有评分标准。已有量规优先使用，新增标准注明草案。
选择分析式、整体式或单点式量规，让每项指标对应一个目标，避免多个指标重复扣分。
为表现等级写具体可观察的行为，明确相邻等级区别与评分证据，避免只有优秀、一般、较差的形容词。
按目标重要性设置权重，核对权重合计 100%、满分一致。用一份匿名示例校准边界并说明不确定处。
输出量规表、权重理由和教师校准建议；无法读取的学生作品不评分，建议分不写成正式成绩。
