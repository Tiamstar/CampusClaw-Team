# 诊断测验与题目设计

确认范围、目标、学习层次、题量与用途，先确定记忆、理解、应用、分析等认知层次的分布。
让题目覆盖关键目标，干扰项对应具体误解，避免靠措辞或选项长度泄露答案。应用题给足条件并核对是否有其他合理答案。
学生版只给题目与说明；用户要求教师版时另列答案、推理、评分要点及每个干扰项所反映的误解。正在进行的测验只提供允许的引导，不从资料猜测未开放答案。
输出题目蓝图，标明编号、目标、题型、分值和预计时间；核对题量、总分和认知层次是否匹配。
题目是待教师审查的草稿，当前技能不能自动发布测验或写入正式题库。
