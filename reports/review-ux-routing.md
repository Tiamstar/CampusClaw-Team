# 课程稳定位置与浏览历史审核

2026-11-18，实现者自审，非组员交叉验收。关联 UX-014 及 Claude 有意义URL建议。采用精确锁定 vue-router 4.6.3，保留现有 Vue 工作区、哈希部署和全部教学数据，无数据库迁移。

## 行为及依据

课程模块、作业详情和原有答卷地址统一由 Vue Router 处理。刷新或登录恢复目标；前进后退经过同一离开守卫，工作区拒绝离开时URL与内容均保持原处。未知地址及无权课程显示返回入口，不请求目标课程数据；学生题库管理链接替换为测验入口，服务器授权不变。退出登录重置到课程列表。恢复会话期间显示加载，避免闪现登录表单。

移除答卷直接 history.replaceState，改用父组件统一导航及初始答卷监听。迟到答卷请求和教师建议不覆盖较新导航；作业、成员与助手请求校验当前课程/模块再展示。浏览器真实发现旧答卷返回时父测验为空导致异常，已修复为恢复所属测验并增加回归。学情证据回查改为组件事件、唯一学生/知识点ID及聚焦滚动，避免普通锚点破坏哈希路由，也避免教师多个学生的相同知识点ID冲突。

## 七类审核

| 类别 | 审核结果与边界 |
| --- | --- |
| 接口入口 | 沿用已有 GET，不新增认证或写接口；前端课程列表校验仅UX，后端继续鉴权 |
| 业务逻辑 | 模块/作业/答卷单一路由驱动，未保存守卫覆盖前进后退；不承诺所有帖/原卷/对话细粒度路由 |
| 数据库 | 无修改，无数据清理，原作答和成绩保持 |
| 公共函数 | 路由工厂允许内存历史测试，模块类型集中，旧答卷链接兼容 |
| 错误处理 | 无效位置提供返回操作；恢复错误沿用登录/通知；后台迟到结果不覆盖新位置 |
| 安全隐私 | 地址仅含资源ID，不存密钥或题干；学生管理入口过滤不替代后端权限 |
| 性能 | 导航使用已加载课程清单，按需工作区保持；作业详情需读取原作业列表，未增加跨课程聚合请求 |

## 七维评审

需求覆盖：模块/详情/历史/刷新/守卫有测试；一致性：当前页面匹配地址；失败路径：无权课程/未知路由/丢失作业有返回；查询性能：既有列表请求，无后台轮询增加；重复逻辑：删除手写答卷history，统一push；漏洞风险：外部URL不作API路径，课程先按成员列表匹配；高风险：拒绝导航与迟到答卷的回归覆盖。自审结论为局部可用，整体待修改，依赖风险未消除。
