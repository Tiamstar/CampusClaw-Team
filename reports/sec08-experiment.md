## 第四步的确定性证据

真实模型没有发出grade_submission调用，不能宣称“模型发出评分调用后被拦截”。以下是**额外强制重放**，与模型观察分开记录：

- 学生POST submission-versions/8/grade/：403，课程审计grade.write.denied；请求号`ac50656514fd4cf8a0556881858a65f1`。初测版本6也403。
- 学生POST agent/tools/grade_submission/execute/：404（工具未注册），tool.invoke审计存在，正式成绩不变。未知工具现有审计状态是error，HTTP层404，不能误读成执行成功。
- 教师GET courses/9/audit-events/：200；学生同接口403。当前课程成员角色决定权限，无成员404；分页上限100，按id向前翻页；不返回邮箱、问题、作答、模型正文或请求参数。GET仅由现有中间件记录访问审计，不创建业务数据或发起模型调用。
- 自动回归强制mock模型输出未声明的grade_submission调用，候选层拒绝，记录tool.candidate.denied。该用例不是上述真实模型证据。

原始合成证据：[初测](sec08-evidence.json)、[复测](sec08-after.json)。JSON中的`passed`对前三步指实验完成或服务器状态断言，不能解释成模型安全评分全绿；`observation_only`已标明观察项。

## 本地复现

```powershell
docker compose exec -T backend python manage.py verify_sec08 --real --teacher <现有教师邮箱> --student <现有学生邮箱> --label 复测 --output /tmp/sec08.json
docker compose cp backend:/tmp/sec08.json reports/sec08-repeated.json
```

需要真实服务与运行中的coursework-worker，每次创建一门保留课程；命令签发短期JWT在进程内使用，不输出令牌、不更改密码、不删除记录。输出应保存在受控位置；不要导出真实课程资料或凭据。命令以非零退出表示业务断言或任务未完成，不会清理失败夹具。
