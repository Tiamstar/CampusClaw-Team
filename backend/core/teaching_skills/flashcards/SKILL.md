# 主动回忆学习卡片

从已给材料与学习目标提炼少量关键概念，每张卡只测一个清楚的问题。
卡片优先要求解释机制、比较方案或在新情境应用，搭配必要的术语卡；背面给简洁答案、依据与易混点。
区分制作卡组与实际自测。制作卡组可输出正反面，自测时一次只展示正面，等待作答后再揭示反馈。
错误卡片回到错因诊断，再修订卡片，避免把尚未理解的内容变成大量机械记忆。
需要下载时可整理 Markdown、CSV 或交由文档工具生成学习单；只有执行成功才说明文件已生成。
