## 七类审核

| 类别 | 保证、依据与失效边界 |
| --- | --- |
| 接口入口 | 沿用任课教师权限；学生真实HTTP403，GET只读取聚合和状态 |
| 业务逻辑 | 连续候选达到时长才转换；未知不能证明恢复，中断/策略变化重置候选 |
| 数据库操作 | 加字段迁移保留旧状态/事件；原全局心跳行锁串行化评估和事件写入 |
| 公共函数 | alert_policy统一校验，observe_alert复用三规则转换；阈值/窗口加入签名 |
| 错误处理 | 非法配置明确失败，倒退时间不推进；心跳过期沿用既有提示 |
| 安全隐私 | 沿用仅教师聚合，不增加提问/答案/模型正文，无外部联系人发送 |
| 性能 | 三规则每课程复用一次汇总，延续全局串行锁；课程量大时需容量复测 |

七维：需求覆盖由AI-006场景和6项回归对应；一致性由锁内状态/事件及重复扫描断言；失败路径覆盖未知/间断/策略/倒退；查询性能未宣称容量收益，保留全局扫描限制；重复逻辑统一观察函数；漏洞风险由原权限与安全门禁核对；高风险区分合成终态任务与真实模型、实际计时与模拟时间、工程默认与团队SLO。结论：本地可用，等待非主实现者交叉验收。
