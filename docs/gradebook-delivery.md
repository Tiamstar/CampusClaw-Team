# E4 成绩册第一阶段：GRD-001 / GRD-002

2026-11-16，Codex 实现与自测。此记录不代表 E4 全部完成，不代替组员交叉验收。学情指标、诊断智能体、HTML/PDF 报告与 MCP 数据工具仍待实施。

## 规则与接口

教师在课程“成绩册”配置最多 50 项作业/测验及百分比权重，合计必须为 100%，权重至多两位小数；拒绝重复、他班、未发布测验和无效满分。策略使用预期版本并在课程行锁内保存。GET 返回已有策略或内存空值，不建记录。

作业取最新提交，补交待复核时不回退旧分；测验按冻结策略取最高完整正式分，并列取最新完成答卷，其他待复核尝试不纳入。不同随机试卷使用各自快照满分。总评使用 Decimal 计算 `Σ(所得分 / 满分 × 权重)`，只在最终展示四舍五入两位。缺交、缺考、待复核、满分失效分别保留状态和 null 总评，不隐式记零。公开来源的撤回及修订不被旧事件覆盖：本阶段直接读取正式评分表当前版本，未引入异步成绩消费者。

教师显式生成不可变快照，记录策略版本、来源记录、评分版本、满分、权重、学生与总评、生成时间和数据指纹。相同版本重复生成返回已有快照。发布需要全部在册学生的各项来源完整且已公开，避免成绩册旁路泄露未公开分数。学生只得到自己的已发布行，无法读取全班、管理策略、生成快照、发布和导出；学生响应指纹只针对其自身可见内容。

来源、策略、成员或姓名变化使全班快照保守失效。GET 再次核对当前数据指纹，学生端隐藏过期快照；教师可回看原快照、撤回、导出或重算，不在 GET 修改快照内容。该策略优先避免陈旧数据继续作为当前总评，可能使未受影响学生也暂时看不到旧总评。

实际 `/api/` 路由：

- `courses/{id}/grade-policy/` GET/PUT，保存需 `expected_revision/items`。
- `courses/{id}/gradebook/` GET/POST，POST 显式生成快照。
- `grade-snapshots/{id}/publication/` POST，明确传入 `published` 布尔值。
- `grade-snapshots/{id}/export/` GET，仅任课教师下载指定快照。

Excel 使用标准 OOXML ZIP，导出与指定快照逐项一致，包含生成时间、指纹、策略与评分版本、满分、权重、缺失状态。所有单元格为 inlineStr 文本，用户标题或姓名即使以 `=` 开始也不成为公式。XML 文本转义并过滤不合法控制字符，下载 no-store。它是可读取的快照明细，未嵌入可执行 Excel 公式。

## 七维审核

| 维度 | 依据与边界 |
| --- | --- |
| 需求覆盖 | 本阶段 GRD-001/002；GRD-003–005 及完整 E4 保持未完成 |
| 一致性 | 不可变快照、来源版本指纹、策略 CAS、课程行锁、重复生成唯一约束，公开前和读取时核对当前来源 |
| 失败路径 | 权重非法拒绝，缺分 null，来源未公开拒绝发布，来源变更不继续展示旧总评，导出错误由界面保留 |
| 查询性能 | 来源以课程与配置 ID 查询，每项批量读取学生提交/答卷；全班快照当前为同步 JSON，未完成大班压测与异步导出 |
| 重复逻辑 | 复用课程身份、正式评分表、Decimal、审计和受控下载；新服务集中定义唯一汇总口径 |
| 漏洞风险 | 不信任客户端分数、拒绝跨班来源，学生响应按本人裁剪，Excel 全文本防注入，导出仅教师 |
| 高风险场景 | 新提交使旧分失效、改分撤公开、满分降低、旧快照不可变、学生探测全班明细均有回归 |

当前没有缺交记零开关，不擅自替教师确认零分。教师需要为缺交学生补充可回查正式评分来源后再发布完整总评。另一名组员独立复核、公网复验与性能指标未执行。
