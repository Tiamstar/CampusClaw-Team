# E1 本地交付与验证

执行者：Codex，实现与自测；不代替李非凡、陈志康的独立交叉验收。关联 QZ-001–007，默认计算口径沿用 architecture-and-contracts.md。

## 行为与接口

- 教师题库五类题、稳定知识点、答案规则、分值和修订；学生没有题库权限。题干、解析复用安全数学 Markdown。选择题答案编号从 0 开始，多选完全匹配，填空去首尾空白且区分大小写。
- 教师按类型/知识点随机组卷，发布校验候选题；每次开考冻结题目、顺序、分值、答案及标签，修订题库不影响旧答卷。个人截止取统一关闭与个人限时的较早者。
- 当前版本与幂等键保存答案，返回服务器版本、保存时间。重复键相同内容重放，内容变化/旧版本返回 409；截止后禁止写入。GET 无写入，过期答卷由每分钟 worker 或交卷入口转换。
- 人工/自动交卷共用状态转换，使用最后成功保存内容；同一测验父锁后取答卷锁，并发开考恢复同一答卷，并发交卷只产生一条评分修订。
- 客观题确定性计分，简答为待复核。AI 建议独立保存，只调用文本模型，不进行图片识别，不影响正式分数。教师逐题复核必须带理由和预期评分版本，改分自动撤回该测验成绩公开。
- 学生只见本人结果，分数需完整正式评分且教师发布；答案/解析在统一公布时刻之后且交卷后开放。成绩发布遇进行中或待复核答卷返回 409。
- PNG/JPEG/WebP 手写图片限制 5 MiB、2000 万像素，每题至多 10 次上传、作答至多引用 3 张。下载再次验证课程身份及答卷所有权。
- 题目统计每学生取最高正式分，并列取最新完成；同一不可变试卷内容分组（随机顺序不影响分组）。正确率与上下 27% 区分度使用十进制；少于 8 人等无效场景返回 null。

实际路由沿用 `/api/`：课程下 `questions/`、`quizzes/`；题目 `questions/{id}/` PUT；测验 `quizzes/{id}/publish/`、`attempts/`、`statistics/`；答卷 `quiz-attempts/{id}/`、`answers/` PUT、`submit/`、`review/`、`suggestion/`、`images/{question_id}/`；图片 `quiz-images/{id}/`。保存需 `expected_revision` 和 `key` 或 Idempotency-Key。发布操作 action 为 publish、close、grades_publish、grades_withdraw。

## 七维审核与限制

| 维度 | 实现依据与边界 |
| --- | --- |
| 需求覆盖 | QZ-001–007 自动测试、真实账号与浏览器证据；E4 成绩册、E5 掌握度等后续联调尚未完成 |
| 一致性 | 题目快照、评分版本、保存收据唯一键、父/子行锁固定次序；不依赖浏览器时钟或客户端分数 |
| 失败路径 | 旧版本/截止拒绝写入，保存失败保留本地文本，模型失败不记零，待复核禁止完整成绩发布 |
| 查询性能 | 题库与答卷分页、标签预取，随机抽题加载本课程候选；大题库和班级容量尚未压测 |
| 重复逻辑 | 复用真实 Membership、模型网关、审计、评分校验与安全 Markdown；计分和截止归服务层 |
| 漏洞风险 | 答案键在服务端裁剪，手写下载授权，模型建议不决定分数；未新增数据库任意查询工具 |
| 高风险场景 | 并发开考/交卷、幂等键冲突、跨用户图片、答案公布前探测、评分修订撤回均有回归测试 |

暂不支持测验归档/编辑已发布配置；调整用新测验，不回写旧快照。自动交卷 worker 最长有约一分钟调度延迟，保存端仍严格执行截止。模型建议当前依附 HTTP 请求，未声称持久化 AI 队列已完成。独立成员审核、公网复验、压力测试保持未验收，不把本地验证等同完整课程项目交付。
