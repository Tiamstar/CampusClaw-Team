# 本地体验使用说明

入口：http://localhost:5174/ 。以下仅描述已实现功能；课程数据由实际账号权限控制。

## 学生

选择课程后，常用入口为AI助手、课程资料、作业、测验和答疑论坛；学习中心包含成绩册、学情、图谱、复习与诊断。手机可用顶部侧栏开关显示或收起课程列表。

课程模块可以复制地址，刷新或重新登录恢复。浏览器前进后退可回到上一个模块。作业详情地址和已有答卷链接可直接打开；无权限时会提示返回。答题未保存或教师评分草稿未保存时，拒绝离开会保持原页面和地址。

学情概览只使用当前时间窗口内正式评分：未知不是零分，一题多个知识点不会重复计入总得分率。优先复习按钮可回查对应证据。这里不是整门课程成绩或绝对能力判断。

复习路径显示最新排期的完成/到期数量。每次分钟数为自己填写的预估，完成提醒不等于掌握知识点。论坛提问会建议已有讨论，可查看后返回继续编辑；收起保留草稿，清空需确认。会话草稿关闭标签页或退出后不保证保留，不是跨设备笔记。

## 教师

课程管理进入题库和试卷识别。识别的题目、图片、共享材料及答案需人工核对，不能将识别成功视为无误。题库答案可以暂缺；组卷后设置分值，包含无参考答案题时需人工批改。选题篮与固定分值在当前标签页按账号和课程恢复，重新访问时会校验题目可用性。

测验中打开答卷进入独立批改工作台。AI建议须逐题复核，保存正式评分与公开成绩是不同动作。论坛作者或任课教师可选择本帖回复为解决方案，也可以重开；教师答复不会自动标为解决。

## 当前限制

全局批改中心已有作业/测验待办、按题对比与本页AI建议。全部细粒度页面地址、错题相似练习和跨设备笔记仍在改进。开发工具依赖审计有未解决告警，不能将本地可体验等同生产安全验收。组员需按验收包独立复验。

## 按题批改测验

教师打开侧栏“批改中心”，选择“测验待批改”，在目标测验点击“按题对比批改”。题号切换相同冻结试卷的题目，学生答案按提交并列，每页最多20份，包含每次作答。核对题干、参考答案和手写图片后，填写本题得分、评语与评分说明，逐份保存。保存只修改这一题，旧评分版本会拒绝覆盖；全部题目有分数后整卷完成。修改会撤回该测验成绩公开，需回测验管理重新公开。切题、翻页或离开前请处理未保存输入；提示不等于自动保存。

按题工作台点击“评阅本页答卷”可依次分析本页整卷，显示每份处理状态。已有相同评分版本的建议会恢复；失败可重试，“当前答卷完成后停止”不会启动下一份。完成后查看本题建议，核对后点击“采用”，再填写评分说明并保存本题正式评分。建议不自动写分；分数保存后旧版建议失效。批量期间保持页面打开，关闭后可重进恢复已完成建议。

真实验收样本位于“CampusClaw 小组项目验收课程”（课程6）的“【图文识别验收】共用几何图两小题（答案留空、人工批改）”。批改中心可打开。旧模型曾误读选择题索引，新建议已带选项字母/文字，旧编码历史不再自动采用。无参考答案时模型可能误判或自拟细则，必须核对实际答案和本课程评分规则，尤其不能仅因建议显示完整就直接保存。

## 检查题图裁切

教师在“试卷识别与整理”打开原卷，对照原页框选题图。可用0–1000四边界坐标微调，并查看裁剪预览；确认字母、数字、单位完整且未带入答案或其他题目后再插入。重新插图后检查并移除错误旧图标记，再保存原卷。已冻结的测验保持原图，不会随题库编辑自动更换；需教师另行处理已发布试卷。
## 课程首页

点击课程卡片进入首页，也可用课程功能中的“课程首页”返回。学生可直接打开未交作业及未交卷答卷，已逾期但允许迟交的作业会单独标明；已截止且不能提交的未交作业仅计数，可到全部作业查看。教师可查看本课程待批改数量，再进入全局批改中心。测验“开放中”表示时间窗口，不表示本人还有作答次数；打开详情核对。首页显示统计时间，点击“刷新概览”更新。最近讨论是最近发帖，不是未读通知。既有资料、作业和答卷地址继续有效。

## 原卷配图纠错

在试卷识别与整理中打开原卷，先选中题组和小题，再选择裁图插入位置（题干、共享材料或解析）。修正已有图时选择“替换”对应图片标记；新增图选择“追加”。核对选区内边缘标注及答案隐私后插入，再保存草稿或保存并同步题库。已冻结测验保持原内容。解析中的图片同样需遵守现有答案公开规则。


## 成绩通知

登录后点击顶部铃铛“通知”，或打开 `http://localhost:5174/#/notifications`。教师新公开的作业与测验成绩会进入学生个人通知中心；点击“查看批改详情”直达对应作业或答卷。打开通知不会自动标为已读，请点击单条或全部标为已读，状态保存在服务器。旧成绩不批量补发通知。

列表按本次读取时的公开状态显示；撤回、重新评分、补交或退出课程后，重新读取会隐藏失效分数或无权通知。打开的页面不是实时推送，请使用“刷新通知”获取最新状态；顶部未读数在可见时每60秒刷新。

保留样本：选择“CampusClaw 小组项目验收课程”（课程6），在作业和测验中查找“【通知验收·合成数据】”标题。作业14对应85/100，测验5答卷8对应10/10，均为工程合成样本，不代表真实教学成绩。

## 题库组合筛选

教师在课程管理进入题库后，可用题干关键词、题型、知识点、答案状态及启停状态一起查找题目，点击“搜索题库”应用。“更多题目”沿用上次搜索条件；只修改下拉框而未搜索，不会把新条件混入已显示列表。“重置筛选”清空条件并回到第一页。材料题组与选题篮独立保留，筛选不会移除已经选择的题目。

“有参考答案”仅表示存有答案键，仍需人工核对正确性。当前未提供基于真实答题统计的难度值，也不会把无数据的题目默认标成中等。

作业入口读取期间显示骨架；网络失败时提供“重新加载”，不会显示为暂无作业。详情重试仍保留原作业地址。首次登录仍先显示登录与页面恢复提示。

## 分享课程讨论

打开论坛帖子后，浏览器地址为 `/#/courses/{课程ID}/forum/posts/{帖子ID}`，可复制给同课程成员。刷新或重新登录会回到该帖；浏览器前进后退可在讨论列表与帖子之间切换。地址不授予权限，非成员仍不能读取。帖子不可访问时可重试原帖或返回列表。未发布问题和教师草稿仍按原标签页恢复规则保留，不会因分享链接自动公开。
