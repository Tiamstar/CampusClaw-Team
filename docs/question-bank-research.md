# 多学科题库与测验调研及改造建议

日期：2026-11-17。执行者：Codex。状态：调研与设计建议，尚未实现以下新能力，未经过教师试用或组员独立验收。

## 结论与问题定位

题库的基本单位应同时支持独立题和“共享材料＋有序子题”的题组；文章内部的多个空还需要独立空位模型。图片应属于材料、题干、选项或解析的内容，而不是只有学生提交答案时才能上传的附件。仅扩展上传后缀无法解决阅读理解、完形填空、共用几何图和组卷问题。

当前实现完成了限定范围内的文本题与事务导入，但限制太多，不能据此称为生产级多学科题库。后续以教师完整工作流是否可用为验收单位，不以字段、接口或题型数量替代体验验收。

## 学科组织方式

下列为结合来源提出的产品设计，不是某厂商已验证功能。

| 场景 | 材料与题目结构 | 作答及评分要求 |
| --- | --- | --- |
| 语文现代文/文言文 | 一篇或多篇材料，保留标题、作者、段落编号、注释、配图；下挂选择、词义、翻译、概括、赏析等子题 | 引用段落可定位；各题独立分值、知识点和评分要点；开放答案教师复核，不做关键词命中即满分 |
| 古诗文比较阅读 | 同一题组的材料甲、乙分别标识，允许图文和注释，关联比较题 | 材料与题目同屏；整组复用；不得随机拆掉其中一首诗或遗漏注释 |
| 英语阅读理解 | passage/图表/广告等共享材料，多道选择或短答子题 | 小题保留顺序，允许文字和图片选项；答案公布前不能经资源描述或下载接口获得答案 |
| 英语完形/语法填空 | 文章内稳定 blank_id 标记；每个空独立选择池或等价答案、分值及匹配规则 | 逐空保存与计分；大小写、空格规则显式配置；等价答案属于同一空，不能与多个空混淆 |
| 七选五/匹配题 | 共享文章＋稳定空位＋整组共用选项池 | 教师设置选项是否允许重复；按 option_id 而非显示字母绑定答案，乱序不改变答案对应关系 |
| 数学/理化综合题 | 共享条件、几何图/实验图/表格＋有序小问；子问还可有自己的图和公式 | 条件和图不重复上传；小问独立分值与步骤评分；手写作答图片独立于命题资源；不自动判定推导语义 |
| 看图作文/写作 | 图片、文字要求、字数提示＋写作子题和维度化评分参考 | 保留完整作答与教师评分，AI 仅建议；字数统计不替代质量评分 |
| 听力（后续） | 一段受控音频＋关联题，播放策略属于测验配置 | 文件授权、失败重试与播放限制须专项设计，不能用图片支持宣称听力已完成 |

## 当前代码缺口

关联既有 QZ-001、QZ-002、QZ-003、QZ-005、QZ-006、QZ-008。以下均为当前实现事实，后续行为变化须单独形成 OpenSpec 变更。

- `backend/core/quiz_models.py`：Question 无材料/题组/命题资源结构；options 是字符串列表。Quiz.rules 只有抽题规则，没有手工固定试卷结构。
- `backend/core/quiz_service.py`：以独立 Question 抽样并打乱 selected；当前快照冻结平面题目。blank 是一个字符串输入，与 answer.values 中任意等价答案匹配，不是多个独立空。
- `frontend/src/QuizWorkspace.vue`：教师需输入从 0 开始的答案编号，选项逐行录入；学生每道填空只有一个输入框，选择题选项以纯文本输出。缺乏题组目录、材料定位和学生视角完整预览。
- QZ-008 与 `docs/quiz-delivery.md`：XLSX/DOCX 仅固定文本模板，主动拒绝图片、Word 原生公式和扫描件。学生简答图片不能替代教师命题图片。不能静默放宽文件校验后声称复杂文档导入已支持。

## 建议的数据与兼容方案

结构为：题库条目（独立题/题组）→有序材料块与子题引用；子题→题干、选项、空位、答案规则、分值与评分参考。试卷另有分区与有序题库条目。先支持一层题组，暂不设计任意深度嵌套。

1. 内容块支持文本/安全数学、图片和表格；图片使用本地受控 asset_id、替代文字、尺寸与说明。材料支持多个具名片段，子题可引用。题干、选项、解析共用内容能力，学生作答附件仍独立管理。
2. 子题、选项和空位使用稳定 ID，顺序与标号只影响展示。多空答案以 blank_id 存储；每空可有多个等价答案。新增规则不得改变历史单空的去首尾空白、区分大小写语义。
3. 题组统一版本并引用明确子题版本；保存时验证全组材料引用、空位映射、答案、分值。组分数由小题求和，材料不单独计分，防止双重计分。材料阅读顺序和子题依赖顺序默认固定。
4. 复制、入库和导入以整组为默认单位；可显式另存单题，但必须带上所需材料。随机抽卷以完整条目为单位，避免同篇文章跨组重复；规则注明“组数/小题数/总分”，不能把一组误算一道单题。分区支持手工选题、排序及整组随机抽取。
5. 沿用开考冻结机制，新增 schema_version，冻结材料、题序、选项映射、资源内容哈希、规则与评分参考。存储资源采用不可变版本引用和保留策略，不能只冻结可覆盖的图片 URL。旧平面答卷保持原评分路径，无需批量重写历史成绩。
6. 学生响应只携带允许看到的材料/题干/选项；答案、解析和评分参考按现有公开策略裁剪。命题草稿图片、解析图片与学生答案图片分别按课程/发布状态/所有权授权；资源元数据也不能泄露答案或个人信息。

随机组卷还需明确公平性：同一抽组规则的候选组应满足既定分值与题型配额，候选不足或总分无法满足时禁止发布并说明原因；不能随机抽到不同总分后再悄悄归一化。难度标签仅为教师标注，不能声称不同阅读材料已经统计等值。统计可按子题版本复算，但同一材料下的小题存在关联，不把题组得分和子题得分重复计入总分或掌握度。

这些是待实现的兼容原则，不是已经冻结的新 API 契约。现有路由、旧答卷和成绩册引用保持可用，新增结构通过显式版本区分。

## 教师与学生工作流

教师入口以“单题、材料题组、文章填空、导入现有试题”组织，内部复用基础题型。题组编辑器：左侧材料/小题目录，中间编辑，右侧学生视角预览；屏幕窄时切换视图。教师点选正确选项，不输入内部编号；每个空直接配置答案，分值与总分实时可见。允许草稿缺项，正式入库/发布前必须完整校验；自动保存显示真实成功、未保存、冲突状态。

上传与粘贴图片可用于材料、题干、选项、解析；支持缩略预览、放大和替代说明。整题截图可先作为题干图片配上明确题型、答案及分值，解决急用，不强制先做 OCR。图片处理在命题草稿中完成，失败不丢文本；已发布资源不能原地替换。

导入划分为两个明确入口：保留现有结构化模板；新增 Word/PDF/截图辅助整理。后者展示原文与候选题组，允许合并/拆分、关联材料、调整题型/选项/空位，标注无法识别和待确认项，全部由教师复核后入库。DOCX 内嵌图片需按文档关系保留锚点，PDF 必须区分文本层与扫描页；不能把“收下文件”当成“正确抽出题目”。OCR/模型仅生成草稿，不猜测缺失答案后自动发布。外部模型处理实际试卷前需另行确定数据范围和授权，本轮未调用。

学生端桌面采用材料与小题同屏，材料可滚动并定位段落；手机按材料→小题布局，可便捷返回材料，避免大面积固定栏遮挡作答。图片可放大、表格和长公式局部横向滚动。目录按题组展示小题作答状态，恢复时回到原小题；切换材料和子题不丢未保存内容。交卷前区分未答、未保存和待上传，不能统一显示“完成”。

批改以题组显示共享材料和当前学生各小题答案，支持按题批阅；客观题确定性评分，主观题按维度给分并由教师确认。成绩、错题和学情继续引用同一快照及正式评分版本，错题回看必须保留理解该题所需的材料。

## 实施顺序与完成条件

| 阶段 | 完整交付单位 | 必须实际验证的结果 |
| --- | --- | --- |
| A：图文材料题组 | 共享材料、有序混合子题、命题图文/公式、手工选题组卷、学生预览、作答和教师批改 | 语文比较阅读、英语阅读、共用图的数学题各完成建题→发布→保存恢复→交卷→批改→公开；旧平面题与成绩兼容；整组复制与抽取不拆散 |
| B：文章多空 | 独立空位、逐空规则/计分、共用选项池、友好编辑器 | 完形、语法填空、七选五各有真实页面案例；重排不改答案映射；非法/缺失空位禁止发布；旧单空等价答案仍同义 |
| C：现有资料辅助导入 | 图片直接命题、含图 DOCX 整理、文本 PDF/扫描稿分流、候选草稿校对及来源定位 | 图像/公式不静默丢失；可人工纠正题组切分；批次校验、原子写入、幂等回执保持；坏包、缺图、低置信识别有明确修复路径 |

图片直接命题属于 A 的必备入口，C 扩展文档自动整理。完整 A 验证后再扩展 B/C，不能只上线上传按钮就结束本轮改造。具体容量、文件上限及识别质量目标须用样本实测确定，不沿用旧文本模板上限宣称覆盖复杂文件。

共同验收边界：跨课程/跨用户资源访问被拒绝；未公开解析无资源旁路；刷新/断网恢复不丢已保存答案；编辑题库不改旧答卷及资源；删除/停用题目不破坏旧试卷；并发修订返回冲突。中文长材料、四种公式分隔符、图片选项、窄屏、键盘导航、坏图/上传失败/空列表均需浏览器验证。迁移前完成仓库外备份和隔离恢复；保留现有真实课程、附件、作答与成绩。以上场景本轮尚未执行，不记作测试通过。
