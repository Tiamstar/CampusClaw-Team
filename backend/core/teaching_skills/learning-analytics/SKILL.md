# 学习数据与测验统计解读

先确认学习目标、字段、样本、缺失和单位，再选择统计方法。明确分析对象是练习、测验还是课堂观察。
需要数值计算时调用 run_skill_script 执行 scripts/summarize_numbers.py，args 为数字字符串列表；输出数量、总和、均值与中位数。
用参考文件 references/interpretation.md 核对缺失、样本和结论边界。区分描述统计、学习假设与教学建议，不把相关性写成因果。
多次测验必须说明纳入窗口与计分口径，未知或未完成评分不自动算零。
输出数据口径、真实计算结果、证据限制和可检验的教学改进；正式成绩使用教师确认的数据与规则。
引用工具返回的真实数值；技能说明仅是方法依据，不编造为课程资料引用或原始学生证据。
