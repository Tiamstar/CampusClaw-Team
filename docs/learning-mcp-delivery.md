# 学情与只读 MCP 本地交付

2026-11-16，Codex 实施及自测。关联 GRD-003、GRD-005、KNO-003 的共享指标部分；本轮不声称图谱着色、知识抽取、复习路径或诊断报告已完成，不代替独立组员验收。

## 共享学情口径

`learning_service.py` 为学情页面、MCP 及后续图谱/报告提供唯一计算逻辑。正式评分来自本课程已提交且完整复核的测验答卷；学生仅纳入本人且测验成绩已公开的记录。教师可显式包含未公开评分，响应与页面都显示范围标记。默认只使用公开评分，不把缺考、待复核、无标签或无效分值当零分。

时间窗口为带时区的 `[start,end)`，归一化 UTC、最长 366 天；默认最近 90 天。按提交时间及答卷 ID 升序，学生 + 稳定题目 ID 取窗口内最近有效评分。知识点归属使用不可变试卷当时的标签，重命名后仍返回证据中的原标签。最近修订移除标签时不会错误恢复旧标签。多标签题对每个知识点计一次；外班标签忽略。

个人掌握度是关联题得分之和 / 满分之和，附有效题数、具体测验/答卷/题目修订/评分版本/发布时间状态。零有效证据为 null/unknown。阈值为低于 60% 待巩固、60%–不足 80% 发展中、80% 及以上较稳固，仅为标签启发式，不作为能力的绝对判断。班级按有数据学生的个人掌握度求均值，附有数据人数，不把无数据学生当零。

趋势按从窗口开始每 7 天划桶，每桶内同题取最近有效正式评分，以有关联知识点题目的得分率展示；不同桶独立，不是累计掌握度。无样本周为 null。每次结果包含窗口、计算策略和对可见数据计算的 data_version 指纹；改分、撤公开、标签改名和权限变化反映在后续读取。

GET `/api/courses/{id}/learning/` 支持 start/end/student_id/include_unpublished。任课教师可查本班，学生只查本人，额外未知参数拒绝；GET 不创建业务记录或调用模型。

## 真正的 MCP 协议入口

`/api/mcp/course-data/` 提供无会话状态的 Streamable HTTP JSON 响应，使用现有短期 JWT Bearer 鉴权；不是共享服务令牌，也不从模型参数取操作者或角色。POST 支持 initialize、ping、notifications/initialized、tools/list、tools/call；GET/SSE 与 DELETE 不提供（405），无服务端主动通知。支持协商 2025-03-26、2025-06-18、2025-11-25；不支持版本拒绝。畸形 JSON 返回 Parse error，额外 schema 字段拒绝，通知不执行工具。

| 工具 | 参数与边界 |
| --- | --- |
| get_grades | course_id，调用与成绩册 GET 相同的 authorized_grades；学生仅本人已发布且来源未失效的快照 |
| get_quiz_statistics | course_id/quiz_id，仅任课教师、测验必须属本班；同一 quiz_statistics 确定性口径，附修订与公开状态 |
| get_knowledge_mastery | course_id，可选 student_id/start/end/include_unpublished，调用与学情页相同授权及计算入口 |

每次执行重新读取 Membership，发现工具不构成永久授权。schema 不接受 SQL、URL、role、伪造用户身份或未开放字段；学生不能借工具读取同学或未公开评分。工具只读，除元数据审计外不写业务数据。结果同时有 content/text 与 structuredContent，权限失败为 isError，不暴露他班是否存在。审计写 actor、course、tool、result、duration、request_id，不写 token、成绩正文或请求密码。

外部客户端的连接 URL 可用 `http://localhost:5174/api/mcp/course-data/`；需自行通过登录取得现有短期 access token，使用 Authorization: Bearer，过期后按正常认证流程更新。本轮没有创建长期共享数据访问凭据，也未将用户 JWT 保存到 MCPServer.token_env；现有课程 Agent 的共享工具配置不自动暴露该登录凭据。官方 MCP 客户端实测地址为 Compose 内网 `http://backend:8000/api/mcp/course-data/`。
