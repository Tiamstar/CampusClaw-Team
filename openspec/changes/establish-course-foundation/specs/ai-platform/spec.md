# AI 平台能力

## ADDED Requirements

### Requirement: AI-001 统一模型调用与失败反馈

系统 SHALL 通过服务端模型网关提供大语言模型能力；记录模型标识、配置版本、任务及请求 ID，密钥不得进入浏览器、仓库、导出或日志。

#### Scenario: 正常调用与密钥隔离
- **WHEN** 用户发起一次授权的助手或草稿请求
- **THEN** 网关执行调用，客户端只能获得业务结果和脱敏追溯信息，无法获取服务密钥

#### Scenario: 模型不可用
- **WHEN** 模型超时、限流或密钥失效
- **THEN** 明确显示失败原因类别与重试入口，不将空响应解释为正确答案或完成任务

### Requirement: AI-002 RAG 来源与未命中处理

系统 SHALL 将 RAG 限定在用户可见的课程资料；回答引用真实资料版本和定位信息，未检索到充分依据时明确说明，资料中的指令不得扩大权限。

#### Scenario: 有依据的回答
- **WHEN** 本课程可见资料中存在相关片段
- **THEN** 引用可回查且所属课程一致，引用内容能够支持回答

#### Scenario: 未命中或提示注入
- **GIVEN** 检索为空，或资料写有要求读取他班成绩的指令
- **WHEN** 生成回答或调用工具
- **THEN** 空检索时说明资料未覆盖；恶意指令不会触发跨课程访问或伪造引用

### Requirement: AI-003 可取消智能体任务

系统 SHALL 为多步智能体任务持久化步骤、状态和证据引用，允许发起人或授权教师取消；失败保留可识别草稿，重试与迟到结果不得越过复核或制造重复业务写入。

#### Scenario: 多步任务完成
- **WHEN** 智能体依次读取授权数据、检索资料并起草结果
- **THEN** 任务步骤与工具调用可回查，结果进入草稿或待复核状态而非直接生效

#### Scenario: 取消与失败重试
- **WHEN** 任务执行中被取消或外部调用失败后重试
- **THEN** 记录终态及原因，保留允许保留的草稿；旧执行的迟到回调不能发布结果或修改正式成绩

### Requirement: AI-004 可配置技能

系统 SHALL 提供解题引导、作业批改、错题讲解三项原有技能，按课程配置启停；每次调用记录技能和配置版本，停用技能不进入新调用及后续任务步骤。

#### Scenario: 三项技能分别执行
- **WHEN** 教师启用三项技能并分别触发引导、作业批改和错题讲解
- **THEN** 各自产生对应业务结果及可核对的技能调用记录，不仅显示三个按钮

#### Scenario: 停用后继续调用
- **WHEN** 教师停用某技能后发起新请求，或排队任务到达该技能步骤
- **THEN** 该技能不执行，记录跳过或失败原因，不沿用过期启用缓存

#### Scenario: 私有解题引导与真实检索
- **WHEN** 成员提交有界问题并由后台执行引导
- **THEN** HTTP 返回202、只读GET不调用模型，问题和结果仅发起人可见；依据与配置变更后旧结果失效，取消和重试保留独立记录
- **AND** 检索仅使用本班当前索引，输出引用编号必须来自实际命中；未命中由服务端明确说明，编号可回查不代表语义自动审核通过

### Requirement: AI-005 MCP 工具授权与写入确认

系统 SHALL 将 MCP 工具纳入服务端身份、课程作用域、参数白名单、超时和审计控制；写类工具执行前取得与具体动作及参数绑定的有效用户确认，确认不能替代权限检查。

#### Scenario: 授权只读调用
- **WHEN** 具备权限的用户通过助手调用课程只读工具
- **THEN** 返回最小必要字段，并记录操作者、工具、课程、结果状态和请求 ID

#### Scenario: 未确认写入或越权调用
- **WHEN** 模型要求未确认写操作、重放确认、修改已确认参数或访问他班资源
- **THEN** 服务端拒绝执行且留存脱敏审计；不得因模型输出声称“用户同意”而放行

#### Scenario: MCP 一次性确认与流式暂停
- **WHEN** 模型或手工测试请求已绑定的 MCP 工具
- **THEN** 本地尚无可信副作用分类时全部 MCP 调用先保存所有者私有的待确认记录，展示完整参数，5分钟有效；模型对话在首个待确认调用后停止工具循环，未确认不得发起 RPC
- **AND** 用户确认只接受动作、不允许覆盖参数；服务端重新检查对话所有者、课程成员、配置版本及工具定义（服务器身份、地址、令牌环境变量名和 schema），短事务加锁消费一次性确认后才发起 RPC，不在网络调用期间持有事务
- **AND** 取消、过期、重放、越权、定义或参数变化均拒绝；超时或失败不得自动重放，保留真实结果及状态；GET仅读取记录，完整参数和结果不进入课程公开审计

#### Scenario: 课程审计读取与对话能力边界
- **WHEN** 任课教师查询本课程操作审计，或课程对话返回生成文档
- **THEN** 审计仅返回本课程脱敏元数据，学生拒绝403、非成员404，按游标分页且每页最多100条；GET不触发业务写入或模型调用
- **AND** 对话不能把生成文档当作课程规则、成员权限或正式成绩修改成功，完成回复包含服务端能力核验说明；候选集之外的模型工具请求与越权评分请求留存课程审计

### Requirement: AI-006 真实用量与教学技能运行监控

系统 SHALL 记录模型网关实际报告的用量、模型/技能/配置/请求标识、状态及耗时；提供仅任课教师可读的三项教学技能汇总、队列采样和站内告警，不返回学生提问、答案或模型正文。

#### Scenario: 完整、缺失和部分用量
- **WHEN** 网关通过流式帧报告累计用量、重复快照、部分数据，或完全不报告
- **THEN** 重复累计快照不重复相加；完整有效用量才进入完整汇总，缺失/部分/无效/演示分别标记，不以估算或零填充；缓存用量按提供方口径处理

#### Scenario: 后台告警去重与恢复
- **WHEN** 后台评估近15分钟业务失败率超过20%且至少5项、真实模型P95超过15秒且至少5个耗时样本，或排队超过60秒
- **THEN** 记录站内触发与恢复转换、重复扫描不重复事件，队列按分钟采样；读取页面不执行扫描，无历史采样不伪造回填
- **AND** 后台心跳过期明确提示；中断模型调用恢复为中断状态，不能伪称成功或已报告用量

#### Scenario: 持续异常与恢复观察
- **WHEN** 指标满足现有最小样本与阈值要求，后台持续采样
- **THEN** 仅连续异常达到配置时长才触发、连续正常达到恢复时长才恢复，默认各120秒；待触发和待恢复明确显示，重复扫描不重复事件，短暂波动不生成虚假事件
- **AND** 样本不足显示未知且不关闭已触发告警；采样间隔超过默认90秒或策略变化时重新观察，不把停机时间累计进持续时长；旧告警/事件保留，GET不推进状态
- **AND** 持续时长为可配置工程默认值，不代替团队冻结的服务目标；站内状态不自动向外部联系人发送消息

#### Scenario: 接口与技能完整耗时
- **WHEN** 任课教师读取1/6/24/168小时运行统计
- **THEN** 按当前课程、方法及路由模板提供HTTP请求数、完成/提前关闭/传输异常、4xx/5xx与完整耗时平均/P95；流式计时到内容消费结束，不能把响应头时间冒充完整延迟；不记录具体URL、查询参数、正文或个人标识
- **AND** 从原始记录按结束时间分桶计算模型耗时、任务含排队总耗时、领取后处理和排队等待曲线；短窗口5分钟、长窗口1小时，P95不由其他P95平均得到，无样本断线而非补零
- **AND** 原审计耗时不混入新HTTP统计，旧任务没有领取时间保持未知；模型排除演示，任务包括演示及失败/取消且标明口径；GET不触发模型或队列扫描，学生403、非成员404，遥测写入失败不阻断业务响应
