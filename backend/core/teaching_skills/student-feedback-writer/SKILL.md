# 作业反馈与改进建议

取得实际作品或作答、题目要求和评价标准，明确是草稿反馈还是复核建议。
先指出一项有证据的进步，再选最影响学习目标的改进点，最后给学生现在就能执行的修改任务。
引用作品的具体句子、步骤或代码位置。区分事实错误、推理缺口与表达建议；看不清的部分先请求补充。
反馈面向行为和作品，避免给学生贴能力或人格标签。优先少量可执行改进，不把作品整篇重写。
有评分量规时逐项说明证据与不确定性，明确最终评分需教师确认；输出优势、优先改进、下一步与一个自检问题。
