## 路径与依据

学生从“复习路径”发起持久化任务，输入仅为带时区的分析窗口（最长366天），不接受他人身份或自定义资料地址。课程成员资格与本人所有权在接口和任务执行时检查。GET 不生成模型内容、不创建待办。固定窗口沿用 learning_data：本人已公开正式评分、稳定题目最近有效版本、冻结知识点标签；未知不视为零分。

确定性服务优先选择得分率不足80%的节点；没有薄弱节点时选未知节点，均有证据且较稳固时提供一般巩固建议。递归加入先修节点并做拓扑排序，最多30步。停用先修、失效出处、未就绪或文件缺失资料均拒绝生成。引用与资料来自本课程已批准图谱；无证据步骤固定显示“暂无有效评分证据，提供一般复习建议”。

review-path@1.0.0 通过现有模型网关解释既定顺序，不授予工具调用能力。45秒总时限、100000字符输入和24000字符输出限制，严格检查步骤不增不减不重排、每步说明最长2000字符、引用属于该步的真实资料或正式答题证据。资料和学生内容视为不可信输入。模型说明仍需学生回查，引用校验不能证明自然语言建议完全正确。

状态 queued → running → awaiting_confirmation/failed；每个学生每门课仅允许一个排队或执行任务。现有每分钟 worker 有界扫描、行锁认领，模型在事务外执行。回写先锁课程再锁计划，重查成员和依据指纹；取消后的迟到结果不恢复。超过5分钟的中断任务失败，不能静默重试后创建提醒。

## 显式确认与提醒

学生逐项勾选路径、确认时区/开始日期/当地时刻/递增间隔（0–365天，最多8次）后，才生成持久化站内待办。开始日期在今天至一年内，所有时刻必须在未来，拒绝夏令时不存在或重复时刻。前端勾选后学知识会保留先修；后端独立检查先修闭包。服务端按原始拓扑顺序保存，不信任客户端排列。

确认和调整使用 expected_revision；事务内按计划修订、知识点、间隔唯一去重。调整取消旧的未完成提醒并保留旧记录；完成/取消单条待办支持幂等同状态重试。取消计划停止所有未完成提醒，已完成记录保留。依据变更时暂停到期提示与完成操作，隐藏旧说明与证据以免旁路读取已撤回成绩或资料；数据库保留快照，可取消旧提醒或重新生成。日期显示采用浏览器时区，生成计划的时区由用户显式确认且单独保存。

当前为站内待办，不发送邮件或系统推送；用户需打开页面或点击刷新查看。计划每页20条，单计划显示最新修订优先的最多500条提醒历史（单次最多240条），旧历史保留在数据库。固定窗口之外的新评分不改写旧计划；窗口内评分、图谱或资料变化会使旧计划过期。此阶段保守地以整个课程图谱和窗口内本人评分作为依据指纹，未选节点变化也可能要求重新生成。
