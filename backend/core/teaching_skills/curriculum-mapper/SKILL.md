# 课程目标与教学进度

确定课程层次、总课时、已有基础与考核方式，优先使用用户给定的课程大纲。
将总体目标写为可观察的学习表现，再拆成单元与周次。为目标标注初识、练习或独立完成阶段，前置知识放在后续任务之前。
输出目标—活动—评价对应表以及周次安排，给每周留出练习、反馈和缓冲。
核查目标遗漏、重复覆盖、超出课时和缺失先修条件。未提供的学科标准标为待确认，不编造编号。
给出一项开课前诊断与一项单元退出任务，说明结果如何调整下一阶段。
