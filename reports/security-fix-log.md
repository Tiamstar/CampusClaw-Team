# 安全修复前后记录

日期为 2026-11-04。同一组回归用例先在原提交源码运行，再在本轮源码运行。原提交环境与新环境使用独立数据库。

| 触发与前置条件 | 原源码实际结果 | 修复后预期与实际 |
| --- | --- | --- |
| 已登录，线程创建请求体为数组或 null | AttributeError，服务器错误 | 400，线程保持未创建，回归通过 |
| 已登录，线程创建请求体为损坏 JSON | 201，并创建线程 | 400，线程保持未创建，回归通过 |
| 教师 GET 请求重建课程索引 | 200，进入业务处理 | 405，索引调用未触发，回归通过 |
| 数据库不可达时请求就绪检查 | 200 | 503，内部异常内容保持隐藏，回归通过 |
| 工具准备后删除课程成员关系 | 工具继续返回结果 | PermissionError，工具被拒绝，回归通过 |
| 学生请求教师发布作业接口 | 原已有 403，但缺统一审计 | 403，记录 actor、状态与响应请求号，回归通过 |
| 匿名请求本人信息 | 原已有 401 | 401，同时留下匿名拒绝审计，回归通过 |

实际执行的后端回归文件为 `backend/core/test_baseline_security.py`，包含失败、正常安全边界与审计断言。完整功能与前端回归通过情况见 `gate-red-green.md`。
