## 行为与兼容

课程成员读取相同的 CourseAssistantConfig，GET 无业务写入；未保存时返回内存默认 v0。仅该课程 Membership.role=teacher 可保存，其他课程教师、学生的建课能力和 is_staff 均不授予本课程编辑权。非成员 404，成员越权写 403。

PUT 保持原路由和原五个配置字段，增加 revision、can_edit。客户端必须回传整数 revision；缺失/过期 409，刷新重试。课程行锁串行化首次创建和后续更新，每次成功保存递增版本并记录操作者、请求号、课程和版本，不把提示词放入元数据审计。提示词 12000 字、技能/工具最多各 20 项，严格布尔校验，全部校验后写入。

旧 AssistantConfig 每账号记录与 UserSkill 原样保留，不把私人提示词、上传内容或外部服务凭据迁入全班配置；旧个人配置不再用于课程运行。课程配置仅绑定内置技能和已连接共享 MCP 服务。上传、详情和删除仍按个人所有权控制，界面说明私人保存且禁止绑定到课程。旧内置技能 ID 在公共配置读取/明确保存时按既有映射解析，GET 不覆盖原存储值。个人外部服务器管理保留，但不再用于课程助手；平台共享服务由平台配置，不通过教师保存自动公开私人服务。

学生界面显示只读配置和版本，禁用应用切换、技能启停、提示词及工具绑定；仍可查看内置技能与自己的上传，使用当前课程应用开始对话。知识库开关是课程默认值，原有每条提问的检索偏好仍可覆盖默认，不保存配置。

## 执行与追溯

普通对话和手动工具测试均加载课程公共版本。运行上下文留 app、展开前模板、技能 ID/名称/版本、知识库偏好和工具引用。每个模型轮次、输出片段、工具执行前后和回答结束前重新检查对话所有权、用户启用状态、课程成员和配置版本。配置更新停止旧运行，保留已发送部分及失败记录，请重新提问；不会撤回已经发送给浏览器的文本。MCP 还在执行入口检查共享/连接/发现状态。脚本和 MCP 返回后，在保存返回文件之前重查配置。

不在模型/网络调用期间持有数据库事务。检查与随后一步执行之间仍有短暂竞态；已发出的外部 RPC 无法回滚。这里保证按步骤重查和阻止后续输出，不承诺外部副作用的串行化撤销。每段流式输出增加数次数据库读取，尚未做压力测试。旧运行上下文缺少版本字段时保持原历史格式，不伪造历史证据。
