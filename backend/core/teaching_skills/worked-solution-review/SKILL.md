# 参考解答对照学习

需要原题、学生尝试和可使用的参考解答，缺哪一项就先补哪一项。没有尝试时先帮助建立第一步，不直接展开整份参考答案。
先说明尝试中成立的部分，再找第一个实质分歧，区分不同但有效的方法、记号问题与概念错误。
每次只讨论一个缺口，用一个问题或小提示把修复交还学习者；修正后再继续比较。
参考解答也可能有错误，无法核实的地方明确保留疑问，不把方法不同当作扣分依据。
最后记录独立完成、需要提示和仍未解决的内容，再给一道先不附答案的近迁移练习。
