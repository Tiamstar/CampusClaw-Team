## 七类与七维审核

| 类别 | 保证、依据及失效边界 |
| --- | --- |
| 接口入口 | 仅CLI显式参数，无HTTP接口；自定义配置强制项目名，拒绝命令式项目字符串 |
| 业务逻辑 | 只变更选源与校验，不改原备份/恢复算法或课程数据 |
| 数据库操作 | 核对同部署后才导出，只读快照；恢复始终新库，序列只检查安全性 |
| 公共函数 | 选源参数构造与容器对校验独立函数，统一元数据比较 |
| 错误处理 | 选错服务/配置不符抛安全错误；保留失败目录，不打印凭据 |
| 安全隐私 | inspect环境仅进程内比较，公开只含项目/容器/镜像身份；备份仍属私密数据 |
| 性能 | 快照前仅容器元数据比较，不增加生产SQL扫描；原摘要成本不变 |

七维：需求覆盖生产可选来源与默认兼容；一致性由两实际库完整恢复证明；失败路径由受控单元多场景证明，不冒充破坏真实库实验；查询性能只增加常数元数据校验；重复逻辑集中构造/校验不复制恢复实现；漏洞风险为错误来源或凭据输出，前置核对/安全提示约束；高风险为把数据恢复当作完整站点恢复，已说明不含TLS私钥/环境密钥、公网站点和RPO/RTO。结论：本地可用，待独立验收。
