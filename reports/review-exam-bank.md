# 试卷题库实现者审核

2026-11-17，Codex 自审，关联 EB-001–004；不是组员交叉签署。行为与实际操作见 [交付说明](../docs/exam-bank-delivery.md)，模型及浏览器记录见 [证据](exam-bank-evidence.json)。

| 检查类别 | 保证、依据及失效条件 |
| --- | --- |
| 接口入口 | 来源/题组/题目只允许真实教师且核对所有者；学生资产读取核对本人冻结答卷及答案公布时刻；只读 GET 不触发识别或业务写入 |
| 业务逻辑 | 草稿待校对，组卷时设分，无答案待人工；全组顺序检查、幂等确认；不能据此保证模型不漏题、图像裁剪正确 |
| 数据库操作 | 课程父锁和来源行锁、版本校验、批次事务；模型/文档解析在事务外；工作者使用领取 token 和租约防止旧结果覆盖 |
| 公共函数 | 复用模型流、Membership、Markdown/KaTeX、题目快照和评分；旧模板严格规则单独兼容，新题库允许空答案 |
| 错误处理 | 文件/图像/文本/模型输出有界，失败保留原卷；前端保存失败保留编辑，不能越过保存直接确认；任务超时/中断需显式重试 |
| 安全隐私 | 整页私有、裁图独立、图片净化、拒绝 DOCX 外链/嵌入/宏；技能只读且运行时复核权限；密钥/模型原文不写审计 |
| 性能 | 每文件/任务限制和单工作者内存上限；题库/任务分页；组卷预览可能逐页寻找所选题，大题库与班级并发未压测 |

| 七维审核 | 依据与结论 |
| --- | --- |
| 需求覆盖 | EB 四项有本地实现及回归；上传→图文题组→入库→设分→发布→学生交卷实测可用；漏题和裁图仍须修改 |
| 一致性 | 事务、幂等、版本、冻结快照及答案发布过滤测试通过；教师后来修订不更改已开考答卷 |
| 失败路径 | 越权、旧版本、坏引用/原卷整页泄露、空答案、过期租约、保存失败均有回归；未做真实断电/高并发工作者演练 |
| 查询性能 | 受限分页、来源索引；材料/资产快照及逐页组卷预览有线性开销，无容量达标结论 |
| 重复逻辑 | 复用现有校验及评分；新解析服务与旧模板解析分离，旧路由保留 |
| 漏洞风险 | 安全检查与对象授权回归降低风险；不把合成资料测试当成对所有恶意 Office/PDF 的安全证明 |
| 高风险场景 | 跨所有者、解析资源、模型晚到、确认重复、原题修订、无答案误记零已覆盖；模型语义完整性无可靠自动保证 |

验证结果：完整统一检查 20 脚本、237 后端、88 前端，生产构建与迁移漂移通过；最后修改后前端 88 项及生产镜像、后端题库/测验 19 项复验通过；OpenSpec 8/8，diff 空白检查通过。安全首轮完整通过，末轮重跑中工具 PATH 缺失及 PyPI 网络超时均如实保留，随后原命令完整重试退出 0，历史/工作树扫描无密钥发现，四套锁文件无已知漏洞、npm audit 0。新增依赖为零。迁移前备份及隔离恢复见交付说明。

分类：基础流程为本地可用；语义漏题、裁图和大题库性能为待改进；“任意格式、完美识别、生产就绪、DeepSeek 已验证、两名组员已验收”等推断无效。公开部署附加项、未约定的恢复/容量指标保持原状态。
