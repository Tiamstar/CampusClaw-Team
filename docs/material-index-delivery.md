# 资料持久化索引交付

2026-11-16，本地实现与 Codex 自测，关联 FND-002、AI-001/002/003。未代表组员独立验收，未合入主干。

## 行为

HTTP 上传与重建只写资料/排队记录，返回 202，不再执行解析或嵌入。上传支持 request_key：教师+课程内相同 key 和相同文件字节/文件名/标题只建一份资料与任务；内容不同 409。网页保留失败重试的 key，修改文件或标题才更新。普通重建支持 key 重放；没有 key 的旧客户端由服务器生成随机 key。资料的活动任务唯一约束和课程行锁防止重复领取；同 key 跨不同操作或重试父任务不允许复用。批量重建返回每份资料任务，已有活动任务直接复用；任务失败不会阻断其他资料。

任务 queued→running→succeeded/failed/cancelled，阶段为读取、提取文本、生成向量及终态。任务记录请求号、来源文件元数据、原文件内容 SHA-256 结果、模型名、阶段时间和重试父 ID。查询、历史 GET 只读。仅指定课程任课教师管理/查看任务，不以全局管理员或其他课程教师替代本课程权限；学生只看安全状态，不返回内部任务或服务错误细节。

上传文件保持不可变，任务在领取、每个嵌入批次和生效前检查发起教师权限；开始和生效检查源文件元数据/归属。没有本课程权限不执行或发布。若课程成员关系变更，新的当前教师可重试，重试任务属于新教师；旧执行仍按原发起教师校验。任务 phase/revision 变化后，旧 expected_revision 返回 409，页面刷新状态。

## 执行与恢复

独立 index-worker 使用现有后端镜像与数据库，不增加外部队列依赖。上传卷只读，解析临时文件改用独立系统临时目录，避免只读挂载失败和同名资料并发覆盖。Docker Linux 主线程执行 SIGALRM 总时限，批次异步调用也使用剩余时间限额；执行窗口 150 秒，租约 180 秒，worker 每 2 秒扫描。单容器 1 GiB 内存限制。worker 退出后队列仍在数据库，重启继续领取；过期 running 转为可重试失败，避免无限自动重复收费。健康检查验证 DB 和过期任务，不把尚未执行的 queued 当成功。

输入最大 50 MiB，支持 TXT/MD/CSV/PDF/DOCX 的文本，提取文本最多 200 万字符、1000 片，嵌入每批最多 64 片。返回向量校验 2048 维、有限数值、数量与模型一致性。不支持的文件可预览或下载，但索引明确失败并给出原因；不假装 OCR 成功。未做 OCR、Office 全格式解析或原生 Windows worker 执行支持。

外部工作在事务外。最终采用 Course→task→entry 锁顺序，整个切片/向量替换在同一事务；数据库写失败回滚到原片段集合。排队/失败/取消时旧片段留存但不用于当前检索，避免“旧结果冒充新版本”。旧图谱、复习和诊断依据可能因此失效，原记录不删除。取消立即终态并释放活动任务位置，重试新增记录；租约 token、状态与期限拦截迟到成功/失败，不能覆盖新的索引。外部请求已经发出时无法撤回调用本身；取消不是外部费用回滚。

## 界面与兼容

教师资料卡显示任务编号/阶段/片段数，提供取消、失败重试、重建和分页历史；学生只显示排队/运行/成功/失败概要。当前课程资料页每 4 秒刷新活动任务，离开课程/退出时停止；刷新失败保留状态并提供重试，不把网络错误当业务失败。跨课程迟到列表响应被丢弃。历史 pending 且无任务的资料显示“尚未建立索引”，不会自动改写或无限显示“正在建立”。

同步 index_material 仅保留显式维护/真实验证命令入口，HTTP 均走队列；不要对同一资料同时运行旧维护命令和后台任务。后续通用任务整合、AI 作业评分和错题闭环另行推进。

## 七类审核与限制

入口：真实成员/教师判断与请求标识校验，HTTP 只排队。业务：失败不是就绪，恢复/重试不伪造索引。数据库：活动唯一约束、课程锁、领取及生效 CAS/token、全量原子替换。公共函数：队列服务共用准备和提交，管理命令兼容。错误：受控业务分类，无原始异常/URL/令牌返回。隐私：学生不见内部任务；文件/检索按课程限制，资料移动时旧任务不能改他班状态。性能：列表与最新任务采用固定次数查询，无逐资料的任务查询，向量批量有限，尚未压测；1000 个片段仍逐条插入，持久化阶段可能较慢。系统时钟和 PostgreSQL 正常、文件通过应用保持不可变是当前保证前提，外部直接改 DB/底层文件不在 HTTP 幂等保证内。

七维审核依据：需求由 FND-002 场景与任务契约覆盖；列表/任务/检索状态一致；错误、取消和重试回归；并发及事务已有针对性测试；准备/提交复用避免两套索引算法；服务错误脱敏和课程隔离；高风险迟到/撤权/移班拒绝。结论为本地已实现且自测可用，待成员独立复核，不能据此宣称性能/公网或人工交叉验收通过。
