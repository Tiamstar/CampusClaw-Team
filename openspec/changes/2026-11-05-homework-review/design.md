# 设计

一次提交包含文字与 0–10 个文件，至少一项非空；单文件沿用教师限制，总计 50 MB，文字 50000 字。保留旧 attachment 并回填多文件关联。旧接口 file 仍可使用。

版本独立评分。状态为未提交、已提交、待批改、已批改；教师点击开始批改进入待批改。保存分数即为已批改，但学生只有在公开后能收到成绩和评语。公开仅面向该提交学生；撤回后接口不返回成绩。历史已公开版本保留自己的成绩。

同一提交父记录行锁串行化补交、评分和公开。评分请求必须携带期望修订号，旧提交及过期修订返回 409；改分需原因，每次保存及公开/撤回写入修订。可选提交键绑定内容指纹，超时重放不会生成重复版本，包括截止后的同内容重放。事务异常清理已写入文件。

预览与下载共用真实课程成员及提交所有者授权。PDF、PNG/JPEG/WebP、DOCX 正文表格、2 MB 内 TXT/MD/CSV 支持预览；其他格式明确提示下载。DOCX 不承诺原始分页、公式及图片保真。内容转义并用无脚本 iframe 隔离，不调用第三方预览服务。

数据迁移前已备份数据库和媒体；先在独立数据库恢复备份并迁移，再升级本地服务。新文字提交会产生空 attachment，禁止直接回退到不支持空附件的旧结构；回滚须维护窗口恢复匹配数据库与媒体备份，或前向修复，防止丢失新增提交。
