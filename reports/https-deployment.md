## 七类与七维审核

| 类别 | 保证、依据与失效边界 |
| --- | --- |
| 接口入口 | Caddy唯一路由，业务直达backend，静态Nginx不代理API；公网DNS/证书待验证 |
| 业务逻辑 | 不改评分/消息结构；仅合成预演，不公开原教学库 |

| 公共函数 | 配置生成独占创建、校验主机/邮箱、生成随机凭据；预演脚本拒绝复用项目/输出目录 |
| 错误处理 | 配置/启动/断言失败非零，停止并保留自建资源；不停止拒绝复用的既有项目 |
| 安全隐私 | 私有backend、覆写代理头、Secure Cookie/CSRF、配置日志仓库外；增加CDN/代理必须重审信任 |
| 性能 | SSE无缓冲实际完成；不声称该短时预演证明容量/SLO |
