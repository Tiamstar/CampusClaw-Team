# UX 基础与组卷效率审核（2026-11-17）

执行者：Codex 工程自测。不是组员交叉验收。关联 UX-001/002/003 与 docs/ux-improvement-targets.md；七方向完整目标仍在进行。

## 改动与依据

- CourseNavigation.vue 提取课程入口，侧栏移除重复16模块；五常用项加学习中心/课程管理二级入口，375px三列换行，保留全部原功能。当前模块分组自动展开，角色隐藏不替代后端权限。
- useToasts.ts / ToastStack.vue：App 操作改为四级队列，最多5条、相同内容去重，成功4秒、信息/警告7秒自动消失；错误手动关闭，卸载清理定时器。各工作区原有局部错误仍保留，未宣称全局统一完成。
- GradebookWorkspace.vue：按百分之一累加权重，即时显示合计；空项、0、超100、三位小数、不足100阻止写请求。后端既有校验保留。
- QuizWorkspace.vue：题库列表统一加入选题篮，去掉整组直接组卷/单题直接组卷的重复动作；保留原卷直接组卷。组卷可统一设分、逐题覆盖并看总分、缺参考答案数量；不把分值回写题库。

## 七类审核

| 类别 | 保证与依据 | 失效边界 |
| --- | --- | --- |
| 接口入口 | 原路由/API结构不变，新增导航组件仅发原模块事件 | 尚未加入稳定模块路由/浏览器前后退 |
| 业务逻辑 | 组卷设分不修改题库；无参考答案提示人工批改 | 选题篮尚未跨刷新保存；尚无难度推荐 |
| 数据库 | 本轮无模型/迁移/业务数据修改 | 不是全库一致性重验 |
| 公共函数 | 通知有界去重，卸载释放定时器 | 各工作区仍有局部通知，未全部接入 |
| 错误处理 | App错误不会被后续成功覆盖，权重非法不发PUT | 超过5条会淘汰最早通知；不可替代持久化通知中心 |
| 安全隐私 | 文本Vue转义，学生不显示教师入口，未写密钥 | 实际授权仍由既有后端检查；无新增安全依赖 |
| 性能 | 导航静态计算，权重线性汇总，不新增API和轮询 | 构建仍有大于500kB主包告警，代码拆分待做 |
