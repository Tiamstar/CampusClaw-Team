## 用户与问题

- 教师：管理本班讲义与助手，组织测验和作业，复核 AI 草稿与评分建议，定位全班薄弱知识点。
- 学生：在自己的课程中检索资料、提问与交作业，完成测验，查看已发布成绩、错题与复习路径。
- 维护者：部署服务、管理密钥与排障；不默认获得教师业务操作权限。

“课程”是本项目业务上下文，“班级”是课程底座的隔离边界。底座实际课程与班级关系尚待核对；接入前确定映射，所有授权使用服务端的真实成员关系，不能把两者简单视为同一个 ID。

## MVP 与完成定义

MVP 包含：可验收的课程底座 + E1、E3、E4、E5。P1 不属于 MVP 通过条件。每项能力同时满足以下条件才算完成：

1. 规约经双方评审，包含操作者、行为、边界、失败结果和证据。
2. 在约定的干净环境中完成部署、迁移和预置账号导入。
3. 主路径、权限负例、失败恢复及数据一致性均有可重复验证结果。
4. 非主实现者以同一提交的规约进行交叉验收，结论为“通过”。
5. 公网地址、提交号、环境与证据入口可追溯，且证据已脱敏。

底座包含的认证、讲义、助手、三项原有技能、作业与错题、MCP、任务和审计不能计为本组新增功能；但不能以“课上已有”为理由跳过最终验收。

## 优先级与边界

| 编号 | 优先级 | 必须保留的能力 | 不承诺的范围 |
| --- | --- | --- | --- |
| E1 | P0 | 五类题、知识点标签、随机组卷快照、版本保存、限时交卷、确定性判分与教师复核、题目统计 | 自动判定作弊、AI 直接定最终分 |
| E3 | P0 | 帖子与回复、治理操作、相似帖提示、带来源的 AI 草稿、教师发布、未答复提醒 | 跨校公共社区、AI 自动发布 |
| E4 | P0 | 成绩项与权重、汇总与 Excel、个人和班级学情、可追溯 HTML / PDF 报告 | 缺失成绩自动记零、无证据的学习能力断言 |
| E5 | P0 | 知识点与先修关系、教师校对、题目资料错题挂接、掌握度与复习路径、间隔提醒记录 | 引入专用图数据库、教师未确认的关系直接生效 |
| E2 | P1 | 数字码或二维码签到、补签、投票抢答、匿名提问与出勤统计 | 精确位置采集、绝对防代签承诺 |
| E6 | P1 | PDF / Office 预览、章节、阅读进度、私有笔记、来源页定位 | 在线编辑 Office、未经转换的格式保真承诺 |
| E7 | P1 | 公告、站内与邮件消息、日历及 iCal 订阅 | 短信推送、第三方日历双向编辑 |

基础层可直接提供引用页定位元数据，不要求为了完成 E3 而先实现整个 E6；基础层任务或站内待办可提供 E3 / E5 提醒，不要求先做 E7 邮件和日历。

## 技术意向

沿用初步设计：Vue 3 + TypeScript、Django + DRF、PostgreSQL，共享登录、模型网关、任务队列与审计。ECharts、KaTeX 属于 P0 展示依赖；PDF.js、LibreOffice、实时通道等随关联功能接入。底座源码版本、任务队列实现、向量检索方案、容器环境和模型提供方尚未确认，不宣称已经接入。
