# 间隔复习计划

读取需要复习的概念、最近学习日期、考试时间与可用时段。没有历史记录时从短期回顾开始，并注明日期假设。
先测回忆再提供答案，将表现分为忘记、困难、基本掌握、轻松回忆，用结果调整下一次复习间隔。
优先安排逾期或反复出错的项目，分散新增内容，控制每次复习量并保留休息。
输出项目、当前证据、复习任务、建议日期和调整依据。示例间隔可用 1、3、7 天，实际按回忆结果修订，不承诺固定间隔保证掌握。
当前平台输出建议表，不会自动写入日历、发送提醒或持久化复习记录。
