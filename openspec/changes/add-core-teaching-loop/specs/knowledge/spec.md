# E5 知识图谱与学习路径

## ADDED Requirements

### Requirement: KNO-001 知识点抽取技能与教师校对

系统 SHALL 提供教师可启停的知识点抽取技能，从本课程可见资料生成带出处的知识点与先修关系候选；只有教师校对批准后进入正式图谱，禁止跨课程关系和有向先修环。

#### Scenario: 从候选到正式图谱
- **WHEN** 教师触发抽取、检查来源、修订名称并批准无环关系
- **THEN** 保存候选及审批记录，生成正式图谱版本并可回查资料依据

#### Scenario: 环、失效来源或技能停用
- **WHEN** 候选含先修环、外班节点、失效引用，或技能已经停用
- **THEN** 不批准不合法关系，停用时不发起调用；失败不会污染正式图谱

### Requirement: KNO-002 稳定知识点与资源关联

系统 SHALL 以稳定知识点 ID 关联本课程资料、题目、错题及帖子；重命名不破坏历史引用，删除采用可追溯停用或迁移，评分快照保留当时的关联版本。

#### Scenario: 多类资源挂接
- **WHEN** 教师将资料和题目关联知识点，学生错题及帖子关联同课程节点
- **THEN** 有权限用户可按知识点检索关联资源，重命名后历史引用仍可解释

#### Scenario: 删除或跨课程挂接
- **WHEN** 停用已引用节点，或把课程 A 题目挂到课程 B 节点
- **THEN** 保留历史版本或明确迁移，拒绝跨课程关联，不留下无法解释的成绩证据

### Requirement: KNO-003 可解释掌握度与图谱着色

系统 SHALL 使用与成绩分析相同的正式评分、知识点关联和时间窗口计算掌握度；图谱显示样本量、计算口径与图例，未知数据不作为低掌握，教师看本班授权汇总、学生只看基于自己已发布正式评分的结果。

#### Scenario: 成绩与图谱一致
- **WHEN** 对同一学生、知识点、窗口和评分版本比较学情页与图谱
- **THEN** 掌握度和样本量一致，着色遵守共同约定阈值，点击可回查本人证据

#### Scenario: 样本为空或他人视图
- **WHEN** 节点没有有效证据，或学生请求同学图谱
- **THEN** 前者使用未知样式，后者被拒绝，不泄露个人学习记录

### Requirement: KNO-004 受约束复习路径与间隔提醒

系统 SHALL 允许学生基于自己的薄弱知识点、正式先修关系与可见资料发起可取消复习路径任务；智能体输出需保留选择依据并满足先修顺序，用户确认计划后才生成可调整或取消的间隔提醒，P0 以持久化站内待办实现。

#### Scenario: 确认复习计划
- **WHEN** 路径任务读取授权数据生成建议，学生确认所选步骤与提醒间隔
- **THEN** 路径只包含可见资源，解释薄弱点及先修顺序，并按用户确认的时区和间隔生成去重待办

#### Scenario: 无证据、取消或资源失效
- **WHEN** 学习证据不足、任务被取消、用户取消提醒或资料失效
- **THEN** 说明不足、不作无依据诊断；停止新提醒或提示资源失效，迟到任务不恢复已取消计划
