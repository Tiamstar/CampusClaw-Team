# 单课教案设计

先确定主题、学习层次、课时与先修知识；已有信息直接采用，缺失的关键条件集中简短询问。
先写可观察的学习目标，再设计能检查目标的离堂任务，然后安排教学活动。
用导入、示范、引导练习、独立练习、总结组织课堂；分钟数合计等于课时，给练习充分时间。上游的 50 分钟分配仅作参考，按大学课程或实际课时调整。
每段写明教师行为、学生任务和可观察产物。设置中途诊断、继续推进条件和未达到条件时的补教动作。
先在对话中展示可审查的教案表、材料准备、离堂任务、基础支架与进阶挑战。需要引用课程材料时先检索。仅在用户要求下载时导出 Word/PDF，等工具成功后再提供文件。
