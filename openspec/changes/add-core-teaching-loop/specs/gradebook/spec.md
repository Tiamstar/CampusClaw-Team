# E4 成绩册与学情分析

## ADDED Requirements

### Requirement: GRD-001 成绩项与确定性汇总

系统 SHALL 允许教师配置本课程成绩项、满分、权重与测验多次取分规则，以正式评分版本确定性汇总；权重合计须为 100%，缺失或待复核成绩标记不完整，不得静默记零、重分配权重或采用 AI 生成分数。

#### Scenario: 按权重重算
- **GIVEN** 已确认成绩项与取分策略，所有参与项都有正式分数
- **WHEN** 教师计算或重新计算成绩
- **THEN** 同一策略及数据版本得到同一结果，可回查来源；评分修订后只纳入最新有效版本

#### Scenario: 权重非法、缺分或旧事件回放
- **WHEN** 权重合计不为 100%、存在缺分，或回放旧评分事件
- **THEN** 分别阻止配置生效、显示不完整或忽略旧事件，不制造重复成绩或覆盖较新分数

### Requirement: GRD-002 成绩发布与 Excel 导出

系统 SHALL 允许教师按同一数据快照发布成绩并导出 Excel，导出包含成绩项、权重、版本与生成时间；学生仅能查看自己的已发布成绩，不得下载全班明细，导出文本须防止公式注入。

#### Scenario: 导出与页面一致
- **WHEN** 教师查看成绩快照并导出
- **THEN** Excel 与页面该快照逐项一致，缺分明确标记，危险文本以文本单元格处理

#### Scenario: 学生请求全班成绩
- **WHEN** 学生直接访问导出、全班列表或他人分数接口
- **THEN** 服务端拒绝，错误与异步下载链接均不泄露他人成绩

### Requirement: GRD-003 学情展示与数据口径

系统 SHALL 为学生基于自己的已发布正式评分展示知识点掌握度和趋势，为教师展示授权班级薄弱点；每个指标包含时间窗口、样本量和评分数据版本，无有效数据时显示未知，不能把缺考、待复核或无关联题当作答错，也不能用统计旁路泄露未发布成绩。

#### Scenario: 以正式答题证据计算
- **WHEN** 查看固定时间窗口的个人与班级知识点统计
- **THEN** 数值可由相同正式评分和关联版本重算，学生与教师看到各自权限范围的数据

#### Scenario: 没有有效证据
- **WHEN** 某知识点没有有效评分题目，或记录全部待复核
- **THEN** 显示未知和样本不足说明，不产生“掌握度 0%”或负面诊断

### Requirement: GRD-004 可复核的诊断智能体与报告

系统 SHALL 提供可启停的学情诊断技能，允许教师发起可取消的多步诊断任务；任务读取授权成绩、答题与图谱快照，生成 HTML / PDF 草稿，每条学习结论引用具体证据，经教师复核后才向目标学生发布。

#### Scenario: 带证据报告发布
- **WHEN** 任务完成、教师回查结论依据并确认发布
- **THEN** HTML 和 PDF 使用同一报告版本，结论关联答题记录、评分版本与知识点，学生仅可查看面向自己的已发布报告

#### Scenario: 数据变化、失败或取消
- **WHEN** 生成期间成绩更新、外部服务失败或任务被取消
- **THEN** 标记快照时间或过期状态，保留可识别草稿且不自动发布；无证据的结论不能通过复核

### Requirement: GRD-005 受控只读 MCP 数据工具

系统 SHALL 提供查询成绩、测验统计、知识点掌握度三类只读 MCP 工具；教师只读取任教课程授权数据，学生只读取自己的已发布结果，工具不得接受模型传入的任意 SQL 或绕过字段限制。

#### Scenario: 三类工具返回可核对结果
- **WHEN** 教师分别调用成绩、统计、掌握度工具，学生调用自己的允许查询
- **THEN** 结果与同一快照页面一致，返回最小字段和数据版本，记录工具调用审计

#### Scenario: 工具参数越权
- **WHEN** 学生指定他人 ID、模型指定他班课程、SQL 或未开放字段
- **THEN** 服务端拒绝或按契约报错，不执行任意查询，也不返回他人明细
