# 作业 AI 批改与错题闭环

2026-11-16；关联 FND-004、AI-001/003/004。执行与审核者为 Codex，本地实现与自测，不代表另一名成员复核或真实学生反馈。

## 接口与行为

- `GET/POST courses/{id}/coursework-settings/`：本班教师保存批改/错题讲解开关与 expected_revision；GET 仅返回已有记录或内存默认值。执行前与结果生效前检查开关及版本。
- `GET/POST submission-versions/{id}/ai-tasks/`：教师提交 grading、request_key、rubric（1–20项，标题、参考答案、各项满分，总和等于作业满分）；学生只能为本人已发布复核未满分项提交 explanation、item_id。HTTP 只受理、202，不调用模型。
- `GET/POST coursework-tasks/{id}/`：查询、cancel/retry 与 expected_revision；同一发起人/版本/技能活动任务唯一，同请求内容幂等，冲突返回409。任务保存阶段、技能版本、配置版本、模型名、请求号、来源快照、租约及重试父记录。
- 原 `submission-versions/{id}/grade/` 增加可选 ai_task_id 和 reviewed_items（id、score、feedback）；必须是最新有效草稿、评分项完全匹配、逐项总和与总分一致。教师明确保存才写正式分数，公开仍由原发布流程控制。整体人工评分继续兼容，不自动推断错题；整体重评清除当前逐项记录，旧历史保留。
- 正式评分修订冻结逐项复核和来源草稿，公开/撤回保留相同项目。学生 grade 仅在公开时包含 reviewed_items。教师可查失效草稿作追溯但不能采用；学生不获得教师草稿。
- `GET courses/{id}/wrong-answers/?page=1`：本人最新提交、当前公开评分，20份提交/页，页码有界；学生界面新增“我的作业错题”。只有未满分的复核项提供讲解入口，无结构的整体分数不推测具体错题。撤回、改分或补交后旧讲解不再返回，历史任务及成绩修订不删除。

## 执行、权限与限制

独立 coursework-worker、DB 持久化任务与现有模型网关，不新增服务凭据。队列重启可恢复；running 180秒租约过期显式失败，用户决定是否重试，不无限自动收费。执行总时限150秒，模型最多60秒且受剩余执行时间限制，容器1GiB、只读上传卷、系统临时目录。取消后状态/token拦截迟到结果，外部已发出的调用不可撤销费用。

锁顺序 Course→Submission→task，HTTP校验、读取与提交分离，模型及附件解析在事务外。领取、附件阶段、模型前和结果生效前校验发起人/学生有效成员关系、最新提交、作业内容、评分版本和配置版本。正式保存再次校验当前任课教师、提交/评分版本和草稿来源，迟到建议不能覆盖成绩。实际应用文件不可变是当前快照保证前提，外部直接篡改存储不在 HTTP 幂等保证内。

读取教师题目附件和本次作答附件，TXT/MD/CSV/PDF/DOCX 单个最多10MiB、合并文本80000字；输入JSON最多160000字符、模型输出最多50000字符。图片、无文本、损坏或超限附件明确失败，不忽略附件后评分。无OCR，无视觉判卷、无编程沙箱判题。所有输入均视为不可信数据，不暴露工具执行能力或其他学生数据；模型输出只能作为有界逐项JSON/讲解，分数有限、范围及精度校验。UI复用净化后的Markdown/KaTeX，公式支持与聊天一致。来源快照留在受控数据库，不写入日志；外部异常仅受控错误，审计记录技能/动作/请求/耗时，token计量仍待补。

当前评分标准属于一次批改请求，不是可复用题库；错题仅覆盖作业已复核评分项，不将测验全部错题统一迁入该入口。AI-004解题引导的独立配置及三技能统一监控仍待整合，不能据此勾选整个基础规约完成。

## 七类/七维审核

入口：课程成员和对象所有者、结构/范围与请求标识；业务：建议与正式成绩分离，缺失信息不评分；数据库：唯一约束、版本、锁序、租约、原子正式修订；公共函数：已有提交/评分/网关及数学净化链路复用；错误：外部信息不直出，失败保留答案成绩；隐私：教师草稿、个人讲解与公开字段分别授权；性能：限输入/任务批量/列表分页，模型不占HTTP和事务，未执行并发负载测试。

需求覆盖以FND-004新增场景为依据，一致性由快照/版本和当前公开投影保证；失败路径由定向回归，查询路径分页但每页每条任务的依据检查仍有额外DB查询，尚未性能优化；准备/校验共用服务避免HTTP和worker各一套算法；漏洞风险以无工具、课程隔离、输出净化和脱敏控制；高风险取消/撤权/补交/撤回保留回归。分类为本地已实现且自测可用，成员交叉复核继续待办。模型语义仍不能由结构校验完全保证，实测发现过错误因果推断，已收紧规则并保留证据；讲解属于可错的学习建议，正式分数始终由教师复核。
