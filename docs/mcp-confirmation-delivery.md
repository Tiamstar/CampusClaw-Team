## 行为与接口

- 全部 MCP 工具进入确认；远端 readOnlyHint 不是可信安全分类。本轮不改变内置课程检索、PDF/DOCX 和技能脚本的独立授权链路。
- 待确认记录绑定用户、对话、课程、配置 revision、工具名、版本、schema、服务器身份/名称/URL/令牌环境变量名和完整参数摘要。参数最多64KiB，5分钟有效。重复请求同一仍有效的动作复用待确认记录。
- `GET /api/agent/threads/{thread}/confirmations/` 只返回所有者私有的最近30条记录；过期状态在读取时推导，无业务写入或外部调用。
- `POST /api/agent/threads/{thread}/confirmations/{uuid}/` 仅接受 `{"action":"confirm"}` 或 `{"action":"reject"}`，额外参数400。每次重新加载候选工具并检查成员、配置和服务定义，执行前再次核验。
- 以短事务行锁认领执行，RPC在事务外运行。两个并发确认只有一次尝试获准。超时/失败/执行进程崩溃均不自动重试；超过两分钟仍 executing 显示结果不确定。此机制不保证外部系统副作用恰好一次。
- 模型流首个 pending 后停止本轮及后续工具循环，不把 pending 当成功；用户显式确认后保留实际工具结果和服务器生成的状态消息。需要继续解读时再发送新消息。
- 完整参数及结果使用 Vue 转义显示；课程审计仅记录动作、对象标识、状态和请求号。确认不能授予超出原候选集的权限。
