# 架构与数据契约

版本：0.1 初稿。以下是建议的逻辑契约，不是已存在的接口或数据库结构；接入底座后按评审结果冻结，不能直接当作运行说明。

## 分层与依赖

```text
教师端 / 学生端：Vue 3 + TypeScript
                │ HTTPS
应用服务：Django + DRF
  ├─ 课程底座：身份、成员、资料、检索、助手、作业、审计
  ├─ P0：quiz / forum / gradebook / knowledge
  └─ P1：interact / preview / notice
                │
共享服务：模型网关 / 技能注册 / MCP / 异步与定时任务 / 文件服务
                │
PostgreSQL + 底座检索存储 + 受控文件存储
```

图中服务均为规划。队列、向量检索和对象存储产品待核对，不额外引入图数据库。知识点先修关系使用关系表和递归查询。实时通道只服务 P1，不作为测验交卷正确性的前提。

## 权限矩阵

| 对象或操作 | 本课程教师 | 本课程学生 | 他班成员 |
| --- | --- | --- | --- |
| 讲义、公开讨论、已发布图谱 | 管理 | 读取允许内容、参与讨论 | 拒绝 |
| 助手、提示词、技能、题库答案键 | 管理 | 不可管理，不可读取未公布答案键 | 拒绝 |
| 学生作答和正式成绩 | 课程内管理，改分须留原因 | 仅本人且遵循发布状态 | 拒绝 |
| AI 草稿、评分建议、班级分析 | 课程内审查 | 仅面向本人的已发布结果 | 拒绝 |
| 学生私有笔记 | 不默认可读 | 仅本人 | 拒绝 |
| 公告、全班导出、出勤总览、管理审计 | 课程内管理 | 无管理与全班明细权限 | 拒绝 |
| 本人复习计划与提醒 | 依具体授权，不能代替学生确认 | 本人确认、调整、取消 | 拒绝 |

匿名帖子和课堂提问只对同学匿名，授权教师和审计仍可追踪真实身份。权限必须在后端、worker、检索、MCP、下载和导出执行，隐藏前端入口不能替代授权。

## 最小数据模型

名称是领域名，不强制底座表名。所有课程对象需绑定真实隔离上下文，关联写入须验证双方归属一致。

| 实体 | 最小字段与不变量 |
| --- | --- |
| CourseContext / Membership | 课程、班级、用户、角色、状态；映射由底座确定，不信任客户端声明角色 |
| Material / Citation | 资料 ID、版本、课程、页码或片段、可见性；引用回查时再次授权 |
| KnowledgePoint / Prerequisite | 稳定 ID、课程、名称、版本、审批状态；正式先修关系不得成环 |
| Question / QuestionRevision | 课程、题型、分值、题干、答案规则、知识点关联版本；答案键只在服务端 |
| Quiz / PaperSnapshot | 规则版本、开放关闭时间、限时、次数、不可变题目快照 |
| Attempt / Answer | 用户、快照、有效截止、作答状态、版本、最后保存时间；正式提交后答案只读 |
| GradeRevision | 来源类型/ID、学生、评分版本、分项分数、复核人、原因、发布时间 |
| GradePolicy / GradeSnapshot | 成绩项、权重、取分规则、版本、来源版本集合、生成时间 |
| ForumPost / Reply | 课程、作者、匿名标记、知识点、治理状态；AI 草稿和公开回复分离 |
| AIArtifact / TaskRun | 类型、课程、发起人、状态、模型/技能版本、数据快照、证据列表、审批记录 |
| ReviewPlan / Reminder | 所有者、图谱/证据版本、确认时间、时区、间隔、取消状态、去重键 |
| AuditEvent | 操作者、课程、对象、动作、请求 ID、时间、结果；改分另有旧值/新值/原因 |

## 状态与一致性

| 对象 | 目标状态与约束 |
| --- | --- |
| 测验配置 | `draft → published → closed → archived`；开考后配置调整不回写已有快照 |
| 答卷 | `in_progress → submitted`；只允许一次正式转换，提交后禁止答案写入 |
| 评分 | `pending → awaiting_review → finalized`；纯客观题可直接 finalized；改分新增版本 |
| 成绩发布 | 与 finalized 分开记录 `unpublished / published`；学生端仅使用已发布版本 |
| 异步任务 | `queued → running → succeeded / awaiting_review / failed / cancelled`；取消与终态使用 CAS 或事务 |
| AI 草稿 | `draft → awaiting_review → published / rejected`；发布为独立授权操作，不由模型触发 |
| 图谱候选 | `proposed → approved / rejected`；批准时校验来源、课程与无环 |

到点定义为 `server_now >= effective_deadline`，此时不再接受保存。有效截止为 `min(quiz.close_at, attempt.start_at + time_limit)`。保存和交卷在同一事务内校验版本、时间和答卷状态，定时任务延迟不得延长窗口。正式答卷使用最后成功保存的答案，客户端未保存内容不进入评分。

相同幂等键和相同请求体重放返回相同结果；相同键但不同内容返回冲突。交卷还需按答卷 ID 做业务唯一约束，不能只靠客户端幂等键防重复。

跨模块成绩事件包含 `event_id、course_context、source_id、grade_revision、student_id、request_id`。消费者按来源与评分版本去重、拒绝旧版本覆盖新版本；建议使用事务 outbox 或等价可重放方案，保证“评分已提交但消息未发送”可恢复。

## 确定性计算口径

以下为本组拟定默认值，需在实现前确认。任何调整新增策略版本，并同步受影响规约与测试。

### 题目和成绩

- 单选、判断完全匹配得满分；多选默认全匹配得满分，否则零分，不默认给部分分。
- 填空默认去首尾空白后与教师维护的等价答案集合匹配，不默认忽略大小写或依赖模型判断；复杂匹配需显式配置。
- 简答和手写识别结果是建议，教师确认后才生成正式分数。模型失败不是零分。
- 总评：`Σ(正式得分 / 成绩项满分 × 100 × 权重比例)`；满分必须大于零，权重合计 100%，采用十进制定点计算，最终展示按四舍五入保留两位小数。
- 缺考、缺交、待复核分别标记，总评不完整时不发布为完整总评。若教师决定缺交记零，必须显式确认该规则和来源，不能隐式记零或重分配权重。
- 测验多次尝试默认取最高的已复核正式分；并列取较晚完成者。策略在测验发布前冻结，页面与导出可见。

### 正确率与区分度

每名学生按冻结的多次取分策略选一份正式答卷，按试卷快照分组，待复核答卷不进入完整统计。

- 正确率：该题得满分人数 / 有效作答人数；部分分不计“全对”，同时可显示平均得分率。
- 区分度：同一快照按总分降序，上下各取 `g = floor(0.27 × N)` 人，计算两组该题平均得分率之差。
- `N < 8`、`g < 2`、上下组重叠或所有总分相同则显示不可计算。总分同分时按夹具中稳定匿名编号排序，输出分组口径，不假装指标有统计显著性。

### 掌握度、趋势与路径

- 学生可见分析只使用已发布正式评分；教师查看未发布评分必须明确标记，不能经图谱或 MCP 间接向学生泄露。
- 在指定窗口内，按学生 + 稳定题目 ID 取最近一条有效正式评分，知识点归属使用该评分时的快照版本。
- 掌握度：`Σ知识点关联题目的所得分 / Σ这些题目的满分`，不把无关联、缺考或待复核计入分母。多知识点题对每个标签各计一次，界面注明这是基于标签的启发式指标。
- 有效题数为零时为未知；初拟图例：低于 60% 为待巩固，60%–不足 80% 为发展中，80% 及以上为较稳固；不作为对学生能力的绝对判断。
- 趋势按相同时间桶口径输出比例与样本量。班级薄弱点为同一窗口内各学生有效掌握度均值，并显示有数据学生数，不把无数据者当零。
- 路径先由无环先修关系限定合法顺序，再由智能体解释弱点及资源选择；证据不足只能提供一般复习建议，不能声称已诊断出缺陷。

## 逻辑接口契约

拟用 `/api/v1/courses/{course_id}/` 前缀；具体路径服从底座现有协议，冻结后另补 OpenAPI。下表不代表当前可调用接口。

| 操作 | 逻辑资源 / 方法 | 关键输入与结果 |
| --- | --- | --- |
| 题库维护 | `questions` POST/PATCH | 题型、版本、规则、知识点；返回教师可见题目版本 |
| 发布与开考 | `quizzes/{id}/publish`、`attempts` POST | 发布规则、幂等键；返回不含答案键的快照与服务端截止 |
| 保存与交卷 | `attempts/{id}/answers` PUT、`submit` POST | 版本、答案、幂等键；返回版本/状态/保存或提交时间 |
| 评分复核 | `attempts/{id}/grade-reviews` POST | 分项分数、原因、预期评分版本；返回新正式版本 |
| 论坛草稿与发布 | `posts/{id}/drafts`、`replies` POST | 请求 ID、引用、草稿 ID、人工确认；返回任务或公开回复 |
| 成绩汇总与导出 | `gradebook` GET、`exports` POST | 策略/数据快照；返回受控查询或导出任务 |
| 知识候选审批 | `knowledge-candidates/{id}/review` POST | 候选版本、批准/拒绝及修改；返回图谱版本 |
| 诊断及复习任务 | `diagnostics`、`review-plans` POST | 授权数据窗口、预期版本；返回任务，不直接发布或创建未确认提醒 |
| 通用任务 | `tasks/{id}` GET、`cancel` POST | 仅授权发起人/教师可操作，返回状态与脱敏原因 |

查询型 MCP 工具拟名为 `get_grades`、`get_quiz_statistics`、`get_knowledge_mastery`，输入经过 schema 校验并由服务端注入身份与范围；不接受任意 SQL、外部 URL 或模型声明的角色。

## 时间、错误与引用

- 持久化使用 UTC，接口返回带时区的 ISO 8601，界面展示课程配置时区；初始演示配置可选 Asia/Shanghai，不能依赖浏览器本地时间判分。
- 错误返回业务码、可公开消息、`request_id` 及可选字段错误；不返回堆栈、密钥或他班对象是否存在。
- 拟定 HTTP 语义：未认证 401；角色不允许 403；不可见对象或不存在 404；字段校验 400；版本/状态/幂等冲突 409；限流 429；外部依赖失败 503。接入后与底座保持一致并冻结测试。
- 引用最小字段：`material_id、material_version、page_or_chunk、course_context、evidence_id`。展示链接时再次授权；删除后显示失效，不重新指向其他文件。
- AI 产物另存 `task_id、model_id、skill_version、data_snapshot_id、reviewer、reviewed_at`；无证据的结论不得伪造出处。
