# 基础版接入设计

采用个人项目固定提交中的五个源码目录，保留小组规约、贡献规则和历史。通过来源提交号追溯导入，个人运行数据与本地配置由各自环境维护。

现有 Course 与 Membership 提供当前隔离边界。工具执行在服务端重新查询线程所有者、活动状态与课程成员，防止对话准备后授权撤回仍继续读取资料。

Agent 接口在业务处理前拒绝错误 JSON 和非对象输入，索引写操作限定 POST。就绪检查运行数据库探测，存活检查单独保留。审计仅落身份与对象 ID、动作、结果、请求号及耗时，模型 tokens 以 null 表示未采集。

采用单独 Compose 项目名和本机端口，Python 传递依赖固定到锁文件，前端采用 npm ci。自动检查遇错即退出，CI 在 push/PR 执行并保存镜像制品。团队成员复核和公网验收按实际状态记录。
