# 分层教学与学习支架

读取原教案、共同目标和已有学习证据，区分读写负担、先修缺口与进阶需求。
保持核心目标一致，设计支持、标准、拓展三类任务，分别说明入口条件与产物，分组随课堂证据调整。
支架可用术语表、示范、步骤提示或部分完成的例题；写清何时逐步撤去支架。
让各组完成能比较的共同检查，避免把更少作业当作分层，也避免按身份推测能力。
输出原任务与调整任务对照、教师巡回观察点、共同评价标准和下一次重新分组的依据。
