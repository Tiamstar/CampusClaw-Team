# 作业功能交付与审核（2026-11-05）

学生在作业页可填写文字、选择多个附件或混合提交。补交保留版本。教师可筛选全班四种状态，开始批改，填写 0 至满分的分数和评语，并选择是否公开；改分需说明，公开可撤回。未公开分数和评语不进入学生响应。

课程资料、题目附件及各提交附件共用文件卡片，支持大窗预览与下载。PDF 和常见图片直接预览，DOCX 为正文表格内容预览，TXT/MD/CSV 为小文件文字预览。DOC、ZIP、Excel、PowerPoint 等显示不支持预览；损坏、加密或不可解析文件明确降级到下载。

## 审核依据

| 维度 | 保证与依据 | 限制 |
| --- | --- | --- |
| 需求覆盖 | HW-001/002/003 与 FND-004 人工批改部分；提交、批改、公开和预览场景有回归 | AI 自动批改及错题闭环尚未实现 |
| 一致性 | 补交、评分、公开均锁定同一父记录；修订号拒绝旧操作 | 组员仍需复核真实多用户体验 |
| 失败路径 | 全部文件先验证；异常回滚数据库并删除文件；幂等键防重试重复 | 进程被强杀时可能遗留未关联媒体，需后续运维清理 |
| 查询性能 | 版本、文件、批改修订使用预取，班级角色单次确定 | 很大班级/超长历史还需分页，本轮未做负载验收 |
| 重复逻辑 | 文件预览下载共用授权；文件卡片与作业工作区独立组件 | Agent HTML 半屏预览继续使用原有组件 |
| 漏洞风险 | 真实成员权限、提交所有者限制、输出转义、隔离 iframe、无第三方文档上传 | DOCX 非原始排版渲染；解析器仍应持续更新 |
| 高风险场景 | 修订号、最新版本检查、有限小数验证、公开撤回及权限测试 | 不宣称完整安全认证或线上容量验证 |

执行者：Codex 自动实施和检查；没有伪造第二位成员审核。归类：本地功能可用；合并 main 前待另一名组员复核。具体自动检查结果见下面记录。
