## 使用方式

进入课程 → 答疑论坛，成员可发帖、回复、按知识点筛选，发帖前可显式查找相似讨论；检索失败仍可提问。匿名仅隐藏帖子作者对同学的身份，教师可识别作者；回复为实名发布，表单明确说明匿名适用范围。教师可置顶、设精华，并创建课程内知识点标签，标签使用独立稳定 ID，尚未实现 E5 的图谱审批及先修关系。

教师设置可启停 `forum-answer-draft@1.0.0`、配置 1–720 小时未答复等待阈值和 IANA 时区，默认 24 小时、Asia/Shanghai。阈值按真实经过时长计算，页面用配置时区显示日期。@教师立即生成其个人待办；未答复扫描为全部任课教师生成持久化待办。

教师生成草稿 → 核对真实资料片段和出处 → 编辑 → 勾选确认 → 公开。学生不能调用、读取未公开草稿；无命中不调用模型，模型失败保留失败状态，人工回复始终可用。模型只能输出回答和已检索片段 ID，无发布工具；服务器校验引用 ID 与标记，发布前再次核对资料哈希。公开回复保留原草稿、生成/确认身份、模型名称、技能版本、请求号、资料内容及片段偏移快照。资料变化后显示失效提示，历史快照不被覆盖。

检索先用本课程关键词；为兼容 C-locale 下中文 pg_trgm 无命中的情况，提供课程内完整标题/知识点短语匹配降级。没有足够命中就如实返回“资料未覆盖”，不能保证任意改写问题均召回。引用与内容是否真正支持结论仍需教师审核。

## 接口与运行

- 课程论坛：`courses/{id}/forum/posts/`、`similar/`、`settings/`、`points/`、`todos/`。
- 帖子：`forum/posts/{id}/`（GET/PATCH）、`replies/`、`drafts/`（GET/POST）。
- 草稿发布：`forum/drafts/{id}/publish/`，必须有 `confirm=true` 和编辑后的正文；重复相同发布返回已有回复，内容不同返回 409。
- 列表每页 20 条，回复每页 50 条，返回 `items/next_page`；教师私有草稿、待办同样分页。
- `python manage.py scan_forum_reminders` 单次扫描；Compose 新增 `forum-worker`，每 60 秒执行一次，依赖后端完成迁移并健康。相同帖子/教师/原因唯一去重，教师答复持有帖子行锁并关闭待办，扫描按相同锁顺序串行判断。生成超过 5 分钟仍 running 的中断草稿标记失败。
- 模型调用在数据库事务外执行，45 秒总时限，正文最多 20000 字；生成期间配置改变，迟到结果失败且不公开。现阶段生成依附 HTTP 请求，进程中断靠后续扫描恢复失败状态，未声称持久化模型队列已完成。
