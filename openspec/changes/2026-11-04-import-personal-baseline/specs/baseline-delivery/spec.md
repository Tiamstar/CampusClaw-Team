# 第一版基础交付

## ADDED Requirements

### Requirement: BASE-001 来源与可重复运行

项目 SHALL 记录导入源码的完整提交号和当前技术栈，并提供从空环境生成配置、构建、迁移与启动的可执行说明。

#### Scenario: 独立本地启动
- **GIVEN** 已安装 README 中的依赖且工作目录没有已有数据库与配置
- **WHEN** 使用配置初始化脚本及 Compose 启动
- **THEN** 生成随机本地凭据，后端完成迁移，数据库和应用就绪检查成功

#### Scenario: 缺少配置或依赖不可达
- **GIVEN** 必需密钥为空或数据库不可达
- **WHEN** 构建后的应用启动或执行就绪检查
- **THEN** 配置错误明确失败，数据库不可达时就绪检查返回 503

### Requirement: BASE-002 请求与工具授权边界

系统 SHALL 在 Agent 业务处理前拒绝非法 JSON，仅允许 POST 启动索引，并在每次工具执行时重新验证线程所有权与课程成员资格。

#### Scenario: 参数非法
- **GIVEN** 用户已登录
- **WHEN** 发送数组、null 或损坏 JSON 到 Agent 线程创建接口
- **THEN** 返回 400，线程数据保持一致

#### Scenario: 无权限与资源不存在
- **GIVEN** 用户的课程资格被撤回或线程已经删除
- **WHEN** 已准备的工具继续尝试读取课程资料
- **THEN** 服务端拒绝，受保护工具保持未执行

#### Scenario: GET 触发写操作
- **GIVEN** 教师已登录
- **WHEN** 用 GET 访问重建索引接口
- **THEN** 返回 405，索引和模型调用保持未触发

### Requirement: BASE-003 检查与证据

项目 SHALL 提供功能与安全检查命令，在失败时返回非零退出码，并记录实际结果、待完成课程要求和审核状态。

#### Scenario: 执行检查
- **GIVEN** 测试依赖、空测试数据库与安全工具可用
- **WHEN** 执行功能和安全检查
- **THEN** 后端测试、前端测试、构建、密钥扫描和依赖审计分别产出可复查结果

#### Scenario: 用例失败
- **GIVEN** 某条回归的实际结果违背断言
- **WHEN** 运行统一检查命令
- **THEN** 返回非零退出码，停止后续检查并保留失败依据
