# 安全边界与聊天公式修复

## Why
登录未限流，已登录用户不受验证码匿名限流约束；GET 助手配置可创建业务记录，成员列表向学生返回邮箱，MCP SSE 未限制累计字节和总耗时。聊天仅渲染 Markdown，LaTeX 原文不能直接阅读。

## What Changes
- 增加数据库共享、行锁保护的认证限流计数；仅存储身份 HMAC，超限返回 429。
- 助手配置读取使用内存默认值，PUT 才持久化；邮箱仅任课教师可见。
- MCP 累计响应上限 3 MiB，整个 RPC 限时；共用 Markdown 接入本地 KaTeX。

## Impact
关联 SEC-001/002/003、AI-001 与工程 GET 无业务写入约束。迁移新增限流表，不改变教学记录；成员接口中学生响应移除 email。E1–E7 不在本轮范围。
