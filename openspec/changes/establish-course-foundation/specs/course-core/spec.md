# 课程底座主路径

## ADDED Requirements

### Requirement: FND-001 身份与课程成员授权

系统 SHALL 向教师和学生提供登录及本班首页，并按服务端成员关系限制课程资源；学生不得修改助手、提示词、技能或他人成绩。

#### Scenario: 成员访问自己的课程
- **GIVEN** 教师 T_A、学生 S_A1 属于课程 A，S_B1 仅属于课程 B
- **WHEN** T_A 与 S_A1 登录并打开课程 A
- **THEN** 两者看到各自角色允许的首页和资源；S_A1 不具有管理入口或对应接口权限

#### Scenario: 替换课程或资源标识
- **WHEN** S_B1 使用课程 A 的接口、文件或已知资源 ID
- **THEN** 请求被拒绝且无资源元数据、正文和统计泄露；未登录请求返回认证失败

### Requirement: FND-002 讲义入库与带来源检索

系统 SHALL 允许任课教师上传本班讲义，校验文件和归属后异步切分建索引；学生只能检索可见讲义，结果包含可回查的资料版本与页码或片段定位。

#### Scenario: 入库后检索
- **GIVEN** T_A 上传包含自制知识点 K1 的讲义
- **WHEN** 入库任务成功且 S_A1 检索 K1
- **THEN** 返回课程 A 的相关片段和可回查出处；结果不混入课程 B 资料

#### Scenario: 解析失败或尚未入库
- **WHEN** 文件损坏、解析失败或任务未完成
- **THEN** 显示真实任务状态与可重试原因，不展示虚假的成功或检索结果

### Requirement: FND-003 助手配置与可追溯对话

系统 SHALL 允许任课教师编辑本班助手、提示词和技能启停；对话须先检查用户和助手归属，使用当前生效配置流式返回并记录调用。

#### Scenario: 教师配置后学生提问
- **GIVEN** T_A 配置课程 A 助手并启用解题引导
- **WHEN** S_A1 提问
- **THEN** 使用该课程的有效配置，展示流式状态和来源，并保留请求 ID 与技能调用记录

#### Scenario: 学生尝试修改配置
- **WHEN** S_A1 直接调用配置接口或指定课程 B 助手
- **THEN** 服务端拒绝操作且不改变任何配置

### Requirement: FND-004 作业批改与错题闭环

系统 SHALL 支持教师发布本班作业、学生截止前提交、助手给出批改建议、教师复核改分和学生查看批改；判错记录进入个人错题并支持错题讲解，所有评分变化可追溯。

#### Scenario: 作业到错题
- **GIVEN** T_A 发布作业，S_A1 在截止前提交含错误的答案
- **WHEN** 批改任务完成且教师复核发布
- **THEN** S_A1 看到正式成绩、反馈与错题，能调用错题讲解；教师改分前后值及原因可追溯

#### Scenario: 过期、重复和批改失败
- **WHEN** 学生截止后新提交、重复发送相同提交，或批改服务失败
- **THEN** 过期新提交被拒绝，幂等重放不产生多份成绩，失败保留原答案并允许授权重试而非伪造分数
