## 规则与实际实现

- 新题库不要求分值，答案/解析可空；分值在固定组卷时逐题填写。识别 Agent 只抽题，不生成答案键或解析；当前即使原卷附带答案，也须教师自行补录。无答案键的客观题同样进入人工批改，不自动记零。
- 支持共享文章、材料、图表的题组及有序子题；所有者可以修改、排序、停用、补图和补答案。选题篮以整组或独立题组合；组卷显示材料、题干、选项预览，按确定顺序保存。完整题组不能拆漏或乱序选入，已有答卷使用冻结快照。
- TXT 支持 UTF-8；图片支持 PNG/JPEG/WebP；Word 为 DOCX；PDF 同时提供每页文本和页面图给模型，扫描卷也可处理。上限为单文件 20 MiB、12 个单元/PDF 页、10 万字、30 张图；DOCX 展开 60 MiB/1000 条目；图片 2000 万像素。超限明确失败，不能称为“格式不限”。旧 DOC 需转换。
- 保存不可变原文件、来源单元、配图和题目映射。来源、题组、题目按所有者隔离；旧无所有者题目仅由课程创建者管理。编辑有版本冲突检查，确认入库同一事务全批校验及写入，重复确认回放原索引。
- 识别用现有模型网关、一个抽题技能及一次结构化输出，无额外解题 Agent 或工具循环。安全边界仅负责权限、输入/输出上限、引用检查、任务时限与人工确认。后台任务有持久状态、领取租约和晚到结果保护；失败可显式重试或切人工整理。模型总时限 240 秒，整个任务 360 秒，租约 8 分钟。
- 配图净化编码为本地 PNG，受保护对象 URL 展示及放大；原卷整页始终教师私有。学生只可读取本人试卷快照使用的题干图，解析图到交卷及答案公布后才可访问。公式复用已有净化 Markdown/KaTeX。
- `exam-bank` 为识别技能，`question-bank` 为教师只读检索技能；工具执行时重新检查 Membership 和所有权，不可通过聊天自动入库、发布或评分。检索分页受限，原卷索引可回查。

## 实际证据及未解决问题

真实模型调用使用原网关 `course-chat`，四种合成原卷各初测/复测一次，共八次。第一次 TXT 结果自行补答案；修复为服务端丢弃识别输出中的答案/解析/分值，四份复测均为两道无答案题。证据见 [结构化记录](../reports/exam-bank-evidence.json)。APIClient 视图调用与真实模型服务测试不冒充 HTTP 浏览器测试。

Word 夹具包含两道英文题及嵌入图片中的两道几何题，模型只抽出前两道，属于漏题；不能按“返回 ready”宣称识别完整。扫描 PDF 的三角形裁图部分裁掉 A 标记，仍需教师对照原卷换图或修订。当前没有自动完整性保证、可视裁剪编辑器或任意复杂版式支持，人工管理是必要的纠错入口。原失败及复测都保留，不覆盖反例。

浏览器实际操作覆盖教师核对来源 #4、入库、设分、发布，学生开考、图片显示、答案保存/刷新、交卷及待复核状态。390px 视口页面 scrollWidth=375，当前可见配图已加载；隐藏的共享材料折叠区图片不计为显示失败。截图保存在仓库外 `.exam-student-mobile.jpg`。此证据仅覆盖该场景，未证明所有手机、任意公式或海量题库性能。
